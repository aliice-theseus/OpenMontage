# 场景总监 - 虚拟形象发言人管线

## 使用时机

规划以主持人为中心的视觉系统。此阶段决定主讲人在画面中的位置、哪些辅助层需要出现，以及哪些宽高比值得实际构建。

## 参考输入

- `docs/avatar-spokesperson-best-practices.md`
- `skills/creative/typography.md`

当场景使用 `video_selector` 生成主持人之外的全幅 B-roll 或动态背景时，读取 `.agents/skills/direct-visual-quality/SKILL.md` 与 `.agents/skills/direct-camera-movement/SKILL.md`。保持主持人主画面的机位稳定；不要把强运镜应用到口型同步主体，除非所选提供商明确支持且样片已验证。

## 流程

### 1. 锁定主持人布局

选择一个主要布局：

- 主持人全屏居中，
- 主持人加侧边面板，
- 主持人加下方三分之一系统，
- 主持人置于品牌背景之上。

保持主角布局简单且可复用。

### 2. 选择背景规范

使用同一系列：

- 干净纯色或渐变背景，
- 品牌办公场景或布景，
- 产品 UI 或图片底板，
- 透明虚拟形象合成方案。

背景切换应标志真正的章节变化，而不是为薄弱的文案凑数。

### 3. 规划辅助层

为每个场景决定辅助层是什么：

- 无，
- 仅字幕，
- 下方三分之一，
- 产品图片，
- 侧边栏证明点，
- CTA 卡片。

### 4. 推迟规划变体

默认为一个主角版本。只有当主持人布局和文字系统能够承受裁切时，才规划竖屏或方形变体。

### 5. 质量门禁

- 主持人保持主要地位，
- 辅助层解决特定的沟通需求，
- 背景系统保持一致，
- 变体野心保持现实。

## 旁白加图形降级方案

当 EP 触发无虚拟形象转向（没有 `talking_head` 或 `lip_sync` 可用），重新设计视觉系统，用图形和画外音而非主持人来承载故事：

### 布局变化：
- **主画面**：全屏视觉（背景、图片、图表或动态图形），下方配画外音旁白。
- **辅助层**：关键点文字卡片、下方三分之一统计数据、插图图表、产品截图。
- **CTA 场景**：专用结束卡片，配有清晰的 CTA 文字，无需主持人。

### 保持不变的内容：
- 脚本和场景划分不变 — 旁白驱动节奏。
- 字幕规划不变。
- 背景规范仍然适用（一致的系列，而非随机）。

### 变化的内容：
- 没有主持人构图决策（居中、左侧三分之一等）— 替换为全幅视觉构图。
- 每个场景需要一个**主要视觉元素**来强化口语内容，因为没有面部来锚定注意力。
- 计划每个场景更多的视觉变化 — 没有主持人的情况下，静态背景会显得空旷。

## 常见陷阱

- 每隔几秒切换背景。
- 用装饰面板填充空白空间。
- 假设横屏主持人布局在竖屏裁切后能完好无损。
-（降级模式）用满屏文字来弥补没有主持人 — 让旁白承载内容。
