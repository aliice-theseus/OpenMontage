# ManimGL 中的 3D

ManimGL 拥有强大的 3D 能力，配备灵活的相机系统。与 ManimCE 不同，ManimGL 不需要特殊的 ThreeDScene 类。

## 基本的 3D 设置

### 创建 3D 对象

```python
from manimlib import *

class Basic3DScene(Scene):
    def construct(self):
        # 获取相机框架
        frame = self.camera.frame

        # 设置 3D 方向
        frame.reorient(20, 70)  # theta, phi（角度制）

        # 创建 3D 对象
        sphere = Sphere(radius=2)
        sphere.set_color(BLUE, opacity=0.7)

        self.add(sphere)
```

## 相机框架控制

### frame.reorient()

`reorient()` 方法是控制 3D 相机方向的主要方式。

```python
# frame.reorient(theta, phi, gamma=0, center=ORIGIN, height=8)

# 前视图
frame.reorient(0, 0)

# 等轴视图
frame.reorient(20, 70)

# 俯视图
frame.reorient(0, 90)

# 侧视图
frame.reorient(90, 90)
```

### 动画化相机移动

```python
class AnimatedCamera(Scene):
    def construct(self):
        frame = self.camera.frame

        # 创建对象
        cube = Cube()
        self.add(cube)

        # 动画化相机旋转
        self.play(frame.animate.reorient(30, 60))
        self.wait()

        # 连续旋转
        frame.add_updater(lambda m, dt: m.increment_theta(0.2 * dt))
        self.wait(10)
```

### 框架方法

```python
# 设置欧拉角
frame.set_euler_angles(theta=30*DEGREES, phi=70*DEGREES)

# 增加角度（用于旋转）
frame.increment_theta(10*DEGREES)
frame.increment_phi(5*DEGREES)
frame.increment_gamma(2*DEGREES)

# 获取当前角度
theta = frame.get_theta()
phi = frame.get_phi()
```

## 纹理表面

### 为 3D 对象添加纹理

```python
class TexturedSphere(Scene):
    def construct(self):
        frame = self.camera.frame
        frame.reorient(20, 70)

        # 创建带纹理的球体
        sphere = Sphere(radius=2)

        # 从 URL 或本地文件应用纹理
        textured_sphere = TexturedSurface(
            surface=sphere,
            # 可以使用 URL 或本地路径
            image_file="path/to/texture.jpg"
        )

        self.add(textured_sphere)

        # 旋转相机
        self.play(frame.animate.increment_theta(360*DEGREES), run_time=10)
```

## 将对象固定在框架中

### fix_in_frame()

在相机旋转时保持 2D 元素（如标签）固定。

```python
class FixedLabels(Scene):
    def construct(self):
        frame = self.camera.frame
        frame.reorient(20, 70)

        # 3D 对象随相机旋转
        cube = Cube()
        self.add(cube)

        # 2D 标题保持固定
        title = Text("3D Cube", font_size=60)
        title.to_edge(UP)
        title.fix_in_frame()  # 保持在屏幕空间
        self.add(title)

        # 旋转相机
        self.play(frame.animate.reorient(50, 80), run_time=3)
```

## 复杂的 3D 场景示例

```python
class Complex3DScene(Scene):
    def construct(self):
        frame = self.camera.frame
        frame.reorient(20, 75)

        # 创建坐标轴
        axes = ThreeDAxes(
            x_range=(-3, 3),
            y_range=(-3, 3),
            z_range=(-3, 3)
        )

        # 创建参数曲面
        surface = Surface(
            lambda u, v: np.array([
                u,
                v,
                np.sin(np.sqrt(u**2 + v**2))
            ]),
            u_range=(-3, 3),
            v_range=(-3, 3),
            resolution=(30, 30),
            color=BLUE
        )
        surface.set_opacity(0.7)

        # 添加网格
        mesh = SurfaceMesh(surface)
        mesh.set_stroke(WHITE, 0.5, opacity=0.3)

        # 添加标题（固定在框架中）
        title = Text("Sinc Function Surface", font_size=48)
        title.to_edge(UP)
        title.fix_in_frame()
        title.set_backstroke(BLACK, 5)

        # 构建场景
        self.add(axes, surface, mesh, title)
        self.wait()

        # 平滑旋转相机
        self.play(
            frame.animate.reorient(45, 70),
            run_time=3
        )
        self.wait()

        # 添加连续旋转
        frame.add_updater(lambda m, dt: m.increment_theta(20 * dt))
        self.wait(10)
```

## 交互式 3D 控制

使用 `manimgl` 运行时，你可以与 3D 场景交互：

- 按 `d` + 移动鼠标：旋转相机
- 按 `z` + 滚轮：放大/缩小
- 按 `r`：将相机重置为默认位置
- 按 `q`：退出交互模式

## 最佳实践

1. **使用 reorient()**：比手动设置欧拉角更简洁
2. **为标签使用 fix_in_frame()**：保持 UI 元素可读
3. **适当的分辨率**：最终渲染使用高分辨率，开发时使用低分辨率
4. **透明体现深度**：设置不透明度 < 1 以透视曲面
5. **光照很重要**：调整光源位置以获得更好的可视化效果
6. **连续旋转**：使用 updater 实现平滑的相机旋转
7. **帧率考量**：3D 场景在开发时可能需要更低的帧率

## 常见模式

### 围绕对象旋转相机

```python
# 360 度旋转
self.play(
    frame.animate.increment_theta(360*DEGREES),
    run_time=10,
```

### 创建地板平面

```python
floor = NumberPlane(
    x_range=(-10, 10),
    y_range=(-10, 10),
    background_line_style={"stroke_color": GREY, "stroke_width": 1}
)
floor.rotate(90*DEGREES, RIGHT)
floor.shift(2*DOWN)
```

### 多个视角

```python
# 从不同角度展示
angles = [(0, 0), (20, 70), (45, 45), (90, 90)]

for theta, phi in angles:
    self.play(frame.animate.reorient(theta, phi))
    self.wait()
```
