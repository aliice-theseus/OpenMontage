# FLUX.1 模型系列

> **提示：** FLUX.2 模型是最新一代，推荐用于大多数使用场景。FLUX.1 模型仍可用于特定需求。

FLUX.1 模型及其专业能力指南。

## 模型概览

| 模型 | 用途 | 备注 |
|-------|---------|-------|
| FLUX1.1 [pro] | 文生图 | FLUX.2 [pro] 提供改进的结果 |
| FLUX.1 Kontext | 图生图 | 推荐使用 FLUX.2 配合参考图像 |
| FLUX.1 Kontext Max | 图生图 | 推荐使用 FLUX.2 [max] 配合参考图像 |
| FLUX.1 Fill | 内补绘制 | 适用于特定的内补绘制任务 |

## FLUX1.1 [pro]

快速可靠的文生图生成。

### 特性
- 强提示遵循能力
- 生产级架构
- 一致、可靠的结果
- 可大规模扩展
- 价格：每张 $0.04

### 提示风格

标准的描述性提示，明确的主体和风格指定。

### 示例提示
```
一只金毛寻回犬幼犬在秋叶中玩耍，温暖的午后阳光，
浅景深，散景背景，欢快的表情，专业宠物摄影风格
```

## FLUX.1 Kontext - 图像编辑

> **建议：** 使用参考图像的 FLUX.2 模型能提供更好的编辑结果。

用于转换和修改的上下文感知图生图编辑模型。

### 特性
- 理解图像上下文
- 保留未编辑区域
- 风格迁移能力
- 物体修改
- 基础到复杂的转换

### 提示策略

#### 基本编辑
简单、直接的指令效果最佳：

```
把车的颜色改成红色
```

```
让天空变成橙粉色的日落
```

#### 受控编辑
明确说明要保留的内容：

```
将场景改为夜晚，同时保持完全相同的
构图和绘画的艺术风格
```

#### 复杂变换
对于戏剧性变化，需具体说明保留内容：

```
将现代办公室改造成维多利亚风格的图书馆，保持相同的
家具布局。保留窗户位置和整体房间
比例不变。
```

#### 风格迁移
参考特定的艺术流派：

```
将这张照片转换为包豪斯艺术风格，使用几何
形状和原色，保持原始构图
和主体位置
```

#### 文本编辑
描述文本位置和整合方式：

```
在窗户中添加"营业中"霓虹灯文字，红色发光字母，
玻璃上有轻微反射，与夜间氛围相称
```

### Kontext 的提示
- 明确说明哪些内容不应改变
- 从简单编辑开始，逐步增加复杂度
- 必要时指定风格保留
- 用于逐步优化

## FLUX.1 Kontext Max

用于复杂构图的高级多参考编辑。

### 特性
- 最多处理 10 张参考图像
- 跨参考图像的最佳编辑一致性
- 复杂场景构图
- 角色一致性保持
- 速率限制：6 个并发请求

### 多参考提示

#### 自然语言参考
自然地描述图像间的关系：

```
图 1 中的人坐在图 2 的咖啡馆里，
穿着图 3 的衣服，采用图 4 的光照风格
```

#### 显式索引
通过编号精确引用图像：

```
将图 1 中人物的上半部分替换为图 2 中的服装，
保持姿势和背景不变
```

### Kontext Max 的提示
- 仔细规划参考图像
- 使用自然语言描述关系
- 指定哪些元素来自哪张图像
- 利用它实现跨场景的角色一致性

## FLUX.1 Fill - 内补绘制

用于物体移除和区域补全的专用工具。

### 特性
- 干净地移除物体
- 智能背景补全
- 纹理感知填充
- 无缝融合

### 使用场景
- 从照片中移除不需要的物体
- 补全部分图像
- 替换特定区域
- 清理图像伪影

### Fill 的提示

描述遮罩区域应填充的内容：

```
用砖墙纹理和常春藤的延续来填充
```

```
用匹配的海浪和沙滩来完成
```

### Fill 的提示
- 提供周围区域的上下文
- 指定纹理和图案的延续
- 描述光照一致性
- 用于清理和移除任务
