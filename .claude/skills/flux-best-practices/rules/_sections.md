# 章节

本文件定义了所有章节、其顺序、影响级别和描述。
章节 ID（括号内）是用于分组规则的文件名前缀。

---

## 1. 核心原则 (core)

**影响：** 关键
**描述：** 适用于所有 FLUX 模型的通用提示原则。在深入学习具体技术之前掌握这些原则。

## 2. 模型选择 (model, flux2, flux1)

**影响：** 高
**描述：** 为您的使用场景选择合适的 FLUX 模型。涵盖 FLUX.2（最新）和 FLUX.1（旧版）模型系列。

## 3. 文生图提示 (t2i)

**影响：** 高
**描述：** 编写有效提示以从文本描述生成图像。

## 4. 图生图编辑 (i2i)

**影响：** 高
**描述：** 使用 FLUX.2 模型编辑和转换现有图像的技术。

## 5. JSON 结构化提示 (json)

**影响：** 中高
**描述：** 使用结构化 JSON 进行复杂的多元素场景构图。

## 6. 颜色指定 (hex)

**影响：** 中
**描述：** 使用十六进制代码进行精确的颜色控制，实现品牌准确的生成。

## 7. 排版与文本 (typography)

**影响：** 中
**描述：** 在生成的图像中渲染文本和排版。

## 8. 多参考编辑 (multi)

**影响：** 中
**描述：** 组合多个参考图像进行风格迁移和构图。

## 9. 正面提示替代方案 (negative)

**影响：** 中
**描述：** 无需负面提示即可实现结果的策略——FLUX 不支持负面提示。
