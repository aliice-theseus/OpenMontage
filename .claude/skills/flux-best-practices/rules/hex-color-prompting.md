# 十六进制颜色提示

FLUX 支持十六进制颜色代码（#RRGGBB）进行精确颜色指定，对于品牌一致性和精确颜色匹配至关重要。

## 语法

直接在提示中包含十六进制代码并附带描述性名称：

```
现代客厅，墙壁涂成 #2C3E50（深蓝灰色），
装饰靠枕为 #E74C3C（鲜艳红色），#F39C12（暖琥珀色）
毯子放在 #ECF0F1（米白色）沙发上
```

## 信号关键词

使用这些关键词来指示颜色指定：

```
颜色 #02eb3c
十六进制 #edfa3c
采用 #FF5733
使用颜色代码 #3498DB
```

## 最佳实践

### 1. 始终搭配描述

切勿单独使用十六进制代码——包含颜色名称：

```
好：#FF6B6B（珊瑚粉）
差：#FF6B6B
```

### 2. 关联到特定物体

清晰地将颜色连接到其目标对象：

```
产品照片，展示一款带有 #1DA1F2（Twitter 蓝）保护壳的智能手机，
放在 #14171A（近黑色）哑光表面上
```

### 3. 限制颜色数量

3-5 种颜色效果最佳。太多会混淆模型：

```
场景配色方案：#2ECC71（翡翠绿）、#3498DB（天蓝）、
#F1C40F（向日葵黄）、#FFFFFF（纯白）
```

## 渐变颜色

```

```

### 三等分色（均匀分布）
```
鲜艳的三等分配色方案：#E74C3C（红色）、#F1C40F（黄色）、

#85C1E9（浅蓝色）、#D4E6F1（淡蓝色）——优雅的层次感
```

## 故障排除

### 颜色不准确
- 在十六进制代码旁添加颜色名称
- 指定颜色应用到的确切物体
- 减少提示中的颜色总数

### 颜色扩散
- 清晰界定哪些物体使用哪些颜色
- 使用空间描述："左边的椅子用 #color"

### 颜色浑浊
- 检查十六进制代码的准确性
- 指定不会影响颜色的光照
- 使用"保持精确颜色 #XXXXXX"来强调
