# FLUX 模型选择指南

根据您的需求选择最佳 FLUX 模型的决策指南。

## 快速决策矩阵

| 优先级      | 推荐模型               |
| ------------- | ------------------------------- |
| 速度         | FLUX.2 [klein]                  |
| 质量         | FLUX.2 [max]                    |
| 平衡         | FLUX.2 [pro]                    |
| 排版         | FLUX.2 [flex]                   |
| 图像编辑     | FLUX.2 [klein], [pro], 或 [max] |
| 本地/免费    | FLUX.2 [dev]                    |
| 内补绘制     | FLUX.1 Fill                     |

## 决策树

```
你的主要需求是什么？

├─ 生成图像（文生图或图像编辑）
│   ├─ 需要最快的生成速度？
│   │   └─ FLUX.2 [klein]（支持最多 4 张参考图像）
│   │
│   ├─ 需要最高质量的输出？
│   │   └─ FLUX.2 [max]（支持最多 8-10 张参考图像）
│   │
│   ├─ 图像中需要文本/排版？
│   │   └─ FLUX.2 [flex]（支持最多 8 张参考图像）
│   │
│   ├─ 需要平衡的速度/质量？
│   │   └─ FLUX.2 [pro]（支持最多 8 张参考图像）
│   │
│   └─ 需要本地/免费生成？
│       └─ FLUX.2 [dev]
│
├─ 需要实时网络信息？
│   └─ FLUX.2 [max]（实况搜索）
│
└─ FLUX.1 系列（仅在用户明确要求时使用）
    ├─ FLUX.1 Kontext - 上下文感知编辑
    └─ FLUX.1 Fill - 内补绘制/物体移除
```

**注意：** 所有 FLUX.2 模型原生支持通过参考图像进行图生图编辑。只需提供源图像作为参考并描述所需的更改。

## 使用场景推荐

### 创意探索/构思

**推荐：FLUX.2 [klein]**

- 快速迭代
- 快速概念测试
- 情绪板生成
- 探索提示变体

### 生产营销素材

**推荐：FLUX.2 [pro]**

- 一致的质量
- 合理的速度
- 规模化成本效益高
- 可靠自动化

### 主打图像/高端内容

**推荐：FLUX.2 [max]**

- 最大细节
- 最佳连贯性
- 支持实况搜索
- 关键视觉值得高端定价

### 排版/标牌/海报

**推荐：FLUX.2 [flex]**

- 卓越的文本渲染
- 可调节质量设置
- 最适合可读文本
- UI 模型和信息图

### 角色一致性

**推荐：FLUX.2 [max] 或 [pro]**

- 多参考支持（最多 8-10 张图像）
- 最佳编辑一致性
- 跨场景保持身份
- 优于 FLUX.1 Kontext 的质量

### 照片编辑/修图

**推荐：FLUX.2 [klein]、[pro] 或 [max]**

- 通过参考图像原生支持图生图
- 风格迁移
- 物体修改
- 属性更改
- 效果优于 FLUX.1 Kontext

### 实时信息

**推荐：FLUX.2 [max]**

- 实况搜索功能
- 当前事件
- 近期新闻可视化
- 天气/位置数据

### 本地开发/测试

**推荐：FLUX.2 [dev]**

- 无 API 成本
- 完全控制
- 微调实验
- 离线能力

### 带排版的编辑内容

```
1. FLUX.2 [max] - 生成基础图像（最高质量）
2. FLUX.2 [flex] - 添加文本叠加层
```

### 角色一致系列

```
1. FLUX.2 [max] - 创建角色参考
2. FLUX.2 [max]/[pro] - 使用参考图像生成一致的变体
3. FLUX.2 [klein] - 必要时快速迭代变体
```

### 电商产品管线

```
1. FLUX.2 [pro] - 批量产品生成
2. FLUX.2 [pro]/[klein] - 产品变体（颜色、角度）使用参考图像
3. FLUX.2 [flex] - 添加促销文字/定价
```

## 基于约束的选择

### 预算有限

- **大批量**：FLUX.2 [klein] 4B
- **需要质量**：FLUX.2 [pro]（性价比最佳）

### 截止日期紧

- **任何任务**：FLUX.2 [klein]
- **质量重要**：FLUX.2 [pro]

### 需要最高质量

- **始终**：FLUX.2 [max]

### 文本必须可读

- **始终**：FLUX.2 [flex]

### 编辑现有图像

- **快速编辑**：使用参考图像的 FLUX.2 [klein]
- **质量编辑**：使用参考图像的 FLUX.2 [max] 或 [pro]
- **替代方案**：FLUX.1 Kontext（推荐 FLUX.2）

### 速率限制敏感性

- **首选**：FLUX.2 模型（24 并发限制）
- **避免**：FLUX.1 Kontext Max（6 并发限制）

## 速查表

```
速度？      → FLUX.2 [klein]
质量？      → FLUX.2 [max]
平衡？      → FLUX.2 [pro]
文本？      → FLUX.2 [flex]
编辑？      → 使用参考图像的 FLUX.2 [klein/pro/max]
免费？      → FLUX.2 [dev]
```

**关键洞察：** 所有 FLUX.2 模型原生支持通过参考图像进行图像编辑。对于编辑任务，推荐使用 FLUX.2 而非 FLUX.1 Kontext。
