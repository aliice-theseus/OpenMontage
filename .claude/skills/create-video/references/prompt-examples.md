# Video Agent 提示词示例

## 完整示例：从需求到生产级提示词

### 输入需求

```
主题：SaaS 创业公司月度公司报告
关键数据：$141M ARR（从 $54M 增长），185 万注册量（+28%），每月 300 万付费视频
客户故事：创作者构建 AI 角色，250 万粉丝，每视频 20 分钟
挑战：自然流量波动大，上周 -16%
时长：约 90 秒
语气：自信的 CEO，数据驱动
```

### 输出提示词

```
格式：彭博社风格公司报告。90 秒。快节奏、数据密集。
创纪录的月份。自豪但理性。

语气：自信、直接、数据驱动。用数字强调亮点。
客户故事是情感核心。挑战坦诚直率——不做修饰。

虚拟形象：身穿简约黑色圆领 T 恤的男士，站在现代玻璃墙
办公室中，正值黄金时段。他身后壁挂显示器显示公司标志，
散发着柔和的蓝色光芒。右侧显示器显示趋势向上的仪表板图表。
身旁的桌子上：笔记本电脑、半杯白咖啡、散落的便利贴。
落地窗透进的温暖午后光线，抛光混凝土上的长长阴影。
极简、专注的创业公司总部。

风格 — SWISS PULSE（Müller-Brockmann）：网格锁定构图。黑色（#1a1a1a）、
白色、电光蓝（#0066FF）、创纪录用暖琥珀色（#FF9500）。Helvetica Bold
标题，Regular 标签。数字要大。动画计数器从 0 开始计数。
重点时刻采用对角线构图。网格划像过渡。无溶解效果。

关键屏幕文本（精确显示）：
- "185 万注册量 — 环比 +28%"
- "$212 万 新订阅收入"
- "$5400 万 → $1.41 亿 ARR"
- "250 万粉丝" 和 "每视频 20 分钟"
- 引语："用技术服务信息，而非分散注意力。"
- "自然流量：占订阅的 65% — 波动大"

音乐：轻快电子乐，有强劲节拍。Tycho 风格遇彭博开题音乐。
随着亮点推进加强，客户故事部分变暖，挑战部分柔和，结尾达到高潮。

---

场景 1 — A-ROLL（8 秒）
[虚拟形象居中，精力充沛，微微前倾]
画外音："一月是创纪录的月份。在获客、收入和产品速度方面都创下新高。
以下是全貌。"
底部三分之一滑入："公司名称 | 2026 年 1 月" 白色文字蓝色条。
网格划像过渡。

场景 2 — 全屏 B-ROLL（12 秒）
[无虚拟形象 — 仅动态图形]
画外音："一百八十五万注册——环比增长百分之二十八。
二百一十二万新订阅收入。两项均为历史新高。"
第 1 层：深色 #1a1a1a 背景，细网格线以 8% 不透明度脉动。
第 2 层："185 万" 从左侧猛冲进来，白色 Bold 140pt。"注册量" 以
电光蓝 32pt 大写逐字打出。"环比 +28%" 以琥珀色出现。
第 3 层：三张统计卡片从右上方级联，间隔 0.3 秒：
         "$212 万 新收入" — "$340 万 Business ARR" — "$300 万 Pro ARR。"
         每个数字从 0 开始计数。
第 4 层：底部走马灯滚动："非品牌搜索 +36% • 品牌曝光 920 万
         • 周订阅 +20.5%"
第 5 层：网格线在"185 万"冲击时向外涟漪。统计卡片后对角线琥珀色条。
硬切。

场景 3 — 全屏 B-ROLL（12 秒）
[无虚拟形象 — 仅动态图形]
画外音："拉远看。十二个月前——五千四百万 ARR。今天——
一亿四千一百万。一年内近三倍增长。"
第 1 层：深色背景，细微网格向上滚动。
第 2 层：动画折线图从左向右绘制。Y 轴：$5000 万到 $1.5 亿。
         最终点"$1.4084 亿"发出琥珀色光并脉动。
第 3 层：里程碑注释在关键数据点处浮入。
第 4 层：下方第二个较小图表——"付费视频"从 91 万到 297 万，相同风格。
第 5 层：细网格线向最终数据点汇聚。扫描线扫过。
网格划像过渡。

场景 4 — A-ROLL（8 秒）
[虚拟形象居中，温暖语调，真诚微笑]
画外音："但数字只是故事的一半。另一半是
在平台上建设的人们。"
底部三分之一："客户聚焦"

场景 5 — 全屏 B-ROLL（12 秒）
[无虚拟形象 — 温暖调色板]
画外音："一个完全在平台上构建的 AI 角色。每视频二十
分钟。两百五十万 Instagram 粉丝。创作者的原则：
用技术服务信息，而非分散注意力。"
第 1 层：深色背景，低不透明度暖琥珀色网格线。
第 2 层："角色名" 大号白色，顶部居中，80pt。
第 3 层：统计数据从右侧级联："250 万粉丝" 以琥珀色计数 —
         "每视频 20 分钟" — "快 7 倍。" 每个都是一个发光节点。
第 4 层：引用卡片向上滑入："用技术服务信息，而非
         分散注意力。" 逐字打出。
第 5 层：温暖光晕。网格线柔化为弧形曲线。
网格划像过渡。

场景 6 — A-ROLL（10 秒）
[虚拟形象居中，严肃/坦诚]
画外音："现在是诚实部分。自然流量驱动着百分之六十五的
订阅量，而且它波动很大。非品牌流量上周下降了百分之十六。
我们已经重建了归因模型，并正在投资 SEO。"
底部三分之一："挑战"

场景 7 — A-ROLL（7 秒）
[虚拟形象居中，情绪提升，直视镜头]
画外音："五千四百万到一亿四千一百万，十二个月。每月三百万
付费视频。一月设定了标杆——现在我们提高它。"
结束卡片：标志居中，蓝色光晕淡入。网格线汇聚。音乐达到高潮。

---

旁白风格：CEO 能量——信念由数据支撑。亮点快节奏。
客户故事温暖。挑战坦诚。以向前冲的势头收尾。
```

## 即用模板

### 科技新闻简报
```
格式：75 秒高能科技简报。风格：彭博社遇 Vice。

虚拟形象：[多显示器工位前的科技休闲风格主持人。
描述服装、显示器内容、桌面物品、灯光。]

风格 — DECONSTRUCTED（Brody）：深灰色 #1a1a1a，铁锈橙 #D4501E。
文字有角度、重叠。粗糙纹理。猛切过渡。

关键屏幕文本：
- [列出每个必须出现的统计数据、引用、账号]

场景 1 — A-ROLL（8 秒）：高能开场。陈述正在发生的事情。
场景 2 — B-ROLL（12 秒）：第一个故事，分层视觉（L1-L5）。
场景 3 — A-ROLL + OVERLAY（10 秒）：第二个故事，分屏。
场景 4 — B-ROLL（10 秒）：第三个故事或戏剧性数据点。
场景 5 — A-ROLL（8 秒）：总结与展望。
```

### 产品对比
```
格式：60 秒对比。[产品 A] vs [产品 B]。数据驱动。

虚拟形象：[评测室中的主持人。桌子上两件产品都可见。]

风格 — DIGITAL GRID（Crouwel）：深色 #0a0a0a，青色 #00D4FF 和琥珀色 #FFB800。
双色编码：青色 = 产品 A，琥珀色 = 产品 B。等宽字体。

关键屏幕文本：
- [每个产品的关键统计数据]
- [定价、功能、差异化因素]

使用分屏 B-roll：产品 A 在左，产品 B 在右。
```

### 战略演示
```
格式：90 秒战略简报。彭博社遇董事会会议。

虚拟形象：[行政人员，T 恤外穿西装外套。会议室带白板框架。]

风格 — SWISS PULSE（Müller-Brockmann）：黑/白 + 蓝色 #0066FF。
网格锁定。Helvetica。动画计数器。网格划像过渡。

关键屏幕文本：
- [框架标签、象限标签、关键引用]

可视化构建框架：绘制坐标轴、标记位置、为标签添加动画。
```

### 社交媒体广告（30 秒）
```
格式：30 秒社交广告。最大能量。竖屏 9:16。

虚拟形象：[创作者风格主持人。环形灯，彩色背景。]

风格 — CARNIVAL SURGE（Lins）：亮粉、黄、青绿。拼贴叠加。
文字巨大且有角度。五彩纸屑。猛切。

三个场景：钩子（8 秒）→ 价值主张（12 秒）→ 行动号召（10 秒）。
文字占每帧的 50-80%。数字猛烈冲击。
```

### 高端报告
```
格式：120 秒投资者级报告。低调的权威感。

虚拟形象：[定制美利奴毛衣。建筑风格房间，漫射自然光。]

风格 — VELVET STANDARD（Vignelli）：黑、白、金色 #c9a84c。
细体全大写，宽间距。慷慨留白。
缓慢交叉溶解。数字有分量地淡入。
```
