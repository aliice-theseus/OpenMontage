# 数学动画的视觉技巧

解释数学概念的高效可视化模式。

## 核心原则

### 1. 渐进揭示
永远不要一次性展示所有内容。逐步构建复杂度。

**不好：** 立即显示完整方程
**好：** 逐项构建方程，解释每一部分

```
场景流程：
1. 展示简单情况：f(x) = x²
2. 增加复杂度：f(x) = ax²
3. 完整形式：f(x) = ax² + bx + c
```

### 2. 变换，而非替换
尽可能将对象变形为新形式，而不是淡出/淡入。

**不好：** FadeOut(equation1), FadeIn(equation2)
**好：** TransformMatchingTex(equation1, equation2)

这保持了视觉连续性并展示了形式之间的关系。

### 3. 颜色即含义
在整个视频中一致地使用颜色来编码含义。

**模式：**
- 输入/给定值：蓝色
- 输出/结果：绿色
- 正在讨论的关键术语：黄色高亮
- 错误/负面：红色
- 中性/辅助：白色/灰色

### 4. 空间关系
位置编码关系：
- 从左到右：变换、时间、因果
- 从上到下：层级、推导
- 中心：注意力焦点
- 边缘：上下文、参考

## 动画技巧

### 高亮与聚焦

**Indicate** - 短暂闪烁以吸引注意力
```python
self.play(Indicate(term))
```

**Circumscribe** - 在重要元素周围画圈
```python
self.play(Circumscribe(equation, color=YELLOW))
```

**FlashAround** - 揭示时的戏剧性关注
```python
self.play(FlashAround(result))
```

**隔离项** - 着色或移动特定部分

```python
step3 = MathTex(r"x = 3")
# 在步骤之间带对齐变换
```

### 几何直觉

**坐标系** - 始终标记坐标轴
```python
axes = Axes(x_range=[-3, 3], y_range=[-2, 2])
labels = axes.get_axis_labels(x_label="x", y_label="f(x)")
```

## 常见视觉隐喻

### 向量作为箭头
- 位置向量：从原点的箭头
- 加法：首尾相接
- 缩放：拉伸/收缩

### 函数作为机器
- 输入从一侧进入
- 变换发生
- 输出从另一侧出来

### 矩阵作为变换
- 展示网格被变换
- 跟踪基向量的去向
- 强调行列式作为面积缩放因子

### 导数作为斜率
- 与曲线相切的切线
- 放大以展示局部线性
- 动画展示斜率随点移动而变化

### 积分作为累加
- 用矩形的黎曼和
- 宽度 → 0 动画
- 曲线下面积填充

## 场景构图

### 黄金布局
```
┌─────────────────────────────────┐
│           标题/上下文           │  （顶部边缘）
├─────────────────────────────────┤
│                                 │
│         主要可视化              │  （中心，最大面积）
│                                 │
├─────────────────────────────────┤
│         方程/公式               │  （底部三分之一）
└─────────────────────────────────┘
```

### 并排对比
```
┌───────────────┬───────────────┐
│    之前 /     │    之后 /     │
│    概念 A     │    概念 B     │
└───────────────┴───────────────┘
```

```
┌─────────────────────────────────┐
│  ┌─────┐                        │
```

## 时间指南

| 操作 | 典型时长 |
|--------|------------------|
| 简单形状创建 | 0.5-1 秒 |
| 文字/方程书写 | 1-2 秒 |
| 变换 | 1-2 秒 |
| 摄像机移动 | 2-3 秒 |
| 吸收暂停 | 0.5-1 秒 |
| 复杂动画 | 2-4 秒 |

### 节奏模式
快-快-慢-快-快-慢

快速动画用于设置，关键时刻放慢速度。
