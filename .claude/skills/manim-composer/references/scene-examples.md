# 场景示例

来自 3b1b 风格视频的示例场景分解。

---

## 示例 1：解释点积

### 场景 1：提出问题
**时长**：约 30 秒
**目的**：用谜团吸引观众

**视觉元素**
- 两个向量 a 和 b 画作箭头
- 点积公式：a · b = |a||b|cos(θ)
- 问号动画

**内容**
开场显示两个向量。展示公式。提出问题："为什么将分量相乘再相加会得到与向量夹角相关的结果？"

**旁白说明**
语气：好奇，略带疑惑。强调公式看起来似乎是任意定义的。

**技术说明**
- 使用 Arrow 表示向量
- MathTex 表示公式
- 对 cos(θ) 项使用 Indicate()

---

### 场景 2：几何解释
**时长**：约 90 秒
**目的**：展示投影解释

**视觉元素**
- 向量 a（水平，蓝色）
- 向量 b（有角度，绿色）
- b 在 a 上的投影（虚线）
- 直角标记
- 长度标签

**内容**
证明 a · b 等于 |a| 乘以 b 在 a 上的投影。动画展示投影落下。从几何角度展示这等于 |a||b|cos(θ)。

**旁白说明**
"点积衡量一个向量在另一个向量方向上的程度。"

**技术说明**
- DashedLine 用于投影
- RightAngle mobject
- animate.rotate() 用于展示不同角度

---

### 场景 3：数值联系
**时长**：约 60 秒
**目的**：连接几何与代数

**视觉元素**
- 坐标网格
- 向量 a = [a₁, a₂]
- 向量 b = [b₁, b₂]
- 高亮显示分量

**内容**
在网格上展示带分量标签的向量。证明为什么 a₁b₁ + a₂b₂ 等于几何解释。使用具体数字。

**旁白说明**
慢慢讲解计算过程。"让我们看看代数如何匹配几何。"

**技术说明**
- NumberPlane 或 Axes
- Brace 用于分量标签
- TransformMatchingTex 用于方程步骤

## 示例 2：傅里叶级数入门

### 场景 1：钩子
**时长**：约 45 秒
**目的**：展示令人惊讶的结果

**视觉元素**
- 方波（尖锐角）
- 平滑正弦波的总和
- 它们之间的变形动画

**内容**
"你可以用完全平滑的正弦波构建一个方波——一种具有尖锐角的东西。"先展示结果，然后承诺解释如何做到。

**旁白说明**
语气：惊奇，略带难以置信。这应该让人感到惊讶。

**技术说明**
- ParametricFunction 用于波形
- Transform 动画用于变形
- 考虑展示 1、3、5 项的构建过程

---

### 场景 2：构建块
**时长**：约 120 秒
**目的**：介绍正弦波作为基础

**视觉元素**
- 单个正弦波
- 频率可视化（更快振荡）
- 振幅可视化（更高/更矮）
- 相位可视化（左/右平移）

**内容**
介绍三个参数：频率、振幅、相位。分别展示每个参数，然后组合。

**旁白说明**
放慢速度。"正弦波有三个我们可以调节的旋钮..."

**技术说明**
- ValueTracker 用于动画参数
- Updaters 使波形响应跟踪器
- 每个参数的标签

---

### 场景 3：叠加
**时长**：约 90 秒
**目的**：展示波可以相加

**视觉元素**
- 两个正弦波（不同颜色）
- 它们的和（第三种颜色）
- 逐点加法可视化

**内容**
证明波的相加意味着在每个点处将高度相加。用两个特定频率的组合演示。

**旁白说明**
"波的加法很简单——在每个点处，只需将高度相加。"

**技术说明**
- VGroup 三个函数图形
- 垂直线显示特定 x 值处的加法
- 动画展示加法过程

## 示例 3：矩阵作为线性变换

### 场景 1：网格变换
**时长**：约 60 秒
**目的**：视觉基础

**视觉元素**
- 2D 坐标网格（NumberPlane）
- 基向量 i-hat 和 j-hat（彩色箭头）
- 网格线变换

**内容**
展示网格。高亮 i-hat (1,0) 和 j-hat (0,1)。应用变换——观察整个网格移动的同时跟踪基向量的落点。

**旁白说明**
"观察当我们应用这个变换时网格发生了什么。注意每个点是如何移动的。"

**技术说明**
- 带有可见网格线的 NumberPlane
- apply_matrix() 方法
- 保持基向量视觉上可区分

---

### 场景 2：基向量决定一切
**时长**：约 90 秒
**目的**：关键见解

**视觉元素**
- 变换后的 i-hat 和 j-hat
- 任意向量 v 作为组合
- v = xi + yj 可视化

**内容**
证明知道 i-hat 和 j-hat 落在哪里就能知道任意向量落在哪里。因为 v = xi + yj，变换后的 v = x(新 i) + y(新 j)。

**旁白说明**
"这里是关键的见解..." 在揭示之前制造悬念。

**技术说明**
- 向量加法动画（首尾相接）
- 系数的缩放动画
- TransformMatchingShapes 用于组合

## 场景过渡模式

### 缩放聚焦
```
完整场景 → 放大到细节 → 解释 → 缩小
```

### 并排构建
```
左侧空白 | 右侧空白
左侧添加 | 比较
右侧添加 | 连接它们
```

### 变换链
```
对象 A → 变换 → 对象 B → 变换 → 对象 C
（全程保持视觉连续性）
```

### 重置与重建
```
复杂场景 → 清除/淡出大部分 → 聚焦一个元素 → 构建新的复杂性
```
