# 画面质感导演

把“高级感”拆成可以锁定、复用和审查的视觉参数。

## 先诊断再加词

| 症状 | 优先检查 |
|---|---|
| 颜色脏、杂、像随手拍 | 色相是否统一，饱和度是否过高 |
| 主体不突出、画面平 | 主光方向、光比与前中后景层次 |
| 画面满、堵、没有重点 | 构图、视线空间和负空间比例 |
| 像塑料或游戏 CG | 皮肤、布料、金属、空气和镜头材质 |
| 单镜头好看但成片廉价 | 跨镜头色调、光源逻辑和风格锚点是否冲突 |

## 工作流

1. 从内容和情绪出发，选择一套主色调，不从关键词库随机拼贴。
2. 用三轴锁定色彩：色相倾向、饱和度、明度/对比度。
3. 为每个场景指定一个可解释的主光源方向和光质。
4. 选择服务叙事的构图，给主体视线或运动方向留下空间。
5. 按景别补充材质：越近越重视皮肤和表面，越远越重视光影和色调。
6. 把稳定参数写入项目视觉锚点，只让场景特定内容变化。
7. 在生成前做冲突检查，在生成后做跨镜头一致性检查。

## 项目视觉锚点

在 `proposal` 或 `scene_plan` 中记录：

```yaml
visual_treatment:
  palette: <主色 + 一个强调色>
  saturation: <低/中/高及原因>
  contrast: <柔和/高反差>
  key_light: <方向 + 光质 + 色温>
  composition_rule: <主要构图法>
  negative_space: <位置与用途>
  lens_texture: <胶片/变形宽银幕/干净数码等>
  material_priority: <皮肤/布料/金属/木纹/空气>
  negative_constraints: <过饱和、塑料皮肤、模糊、畸变等>
```

场景提示必须继承该锚点。除非剧情要求刻意反差，不要每个镜头更换调色系统。

## 冲突规则

- 一个画面只建立一个主光源逻辑；补光只做分离和点缀。
- 不混用超过三个风格锚点；优先一套视觉语言加少量材质词。
- 中心对称构图不要同时使用会破坏对称的强环绕运动。
- 留白必须位于视线、运动或情绪需要的位置，不是随意空置。
- 不用 `4K`, `cinematic` 等兜底词替代具体的色调、光线和材质。
- 胶片颗粒、光晕和手持微动应克制，避免滤镜堆叠。

## 阶段应用

- `proposal`：选定主色调、光影方向和材质基准。
- `scene_plan`：为每个镜头填写构图、留白、景别和主光源。
- `assets`：将项目锚点与场景特定描述组合成生成提示。
- `edit/compose`：维持色彩连续性、景别节奏和纹理强度。
- `review`：检查是否存在风格漂移、塑料材质、过饱和或主光源跳变。

## 交付检查

- 全片是否锁定一套主色调，且强调色使用克制？
- 每个镜头能否指出主光源的方向、软硬和色温？
- 主体周围是否有服务视线或运动的呼吸空间？
- 景别是否形成远、中、近的节奏？
- 特写是否包含与主体相关的真实材质，而非通用清晰度词？
- 负面约束是否排除过饱和、塑料皮肤、模糊和畸变？

需要调色、光位、构图与材质词库时，读取 [references/visual-treatment-library.md](references/visual-treatment-library.md)。
