# Video Agent 提示示例

## 完整示例：从简报生产提示

### 输入简报

```
主题：SaaS 创业公司的月度公司报告
关键数据：$141M ARR（从 $54M 增长）、185 万注册（+28%）、每月 300 万付费视频
客户故事：创作者构建 AI 角色、250 万粉丝、20 分钟/视频
挑战：自然流量波动，上周 -16%
时长：约 90 秒
语调：自信的 CEO，数据支持
```

### 输出提示

```
FORMAT：Bloomberg 风格的公司报告。90 秒。快节奏，数据密集。
破纪录的月份。自豪但分析型。

TONE：自信、直接、数据支持。亮点用数字重击。
客户故事是情感核心。挑战诚实——不转移话题。

AVATAR：身穿简单黑色圆领T恤的男性，站在现代玻璃墙办公室
黄金时段。他身后，壁挂显示屏显示公司 Logo
柔和蓝光。右侧显示器显示仪表板，图表呈上升趋势。
他旁边的桌子：笔记本电脑、半杯白咖啡、散落的便利贴。
午后暖光透过落地窗，抛光混凝土上的长影。
极简、专注的创业公司总部。

STYLE — SWISS PULSE (Müller-Brockmann)：网格锁定构图。黑色 (#1a1a1a)、
白色、电蓝色 (#0066FF)、记录用暖琥珀色 (#FF9500)。Helvetica Bold
标题、Regular 标签。数字大号。动画计数器从 0 计数。
强调时刻的对角线构图。网格擦除过渡。无溶解。

CRITICAL ON-SCREEN TEXT（字面显示）：
- "1.85M 注册 — +28% 月环比"
- "$2.12M 新订阅收入"
- "$54M → $141M ARR"
- "250 万粉丝" 和 "20 分钟 / 视频"
- 引用："Use technology to serve the message, not distract from it."
- "自然流量：65% 订阅 — 波动"

MUSIC：有驱动节拍的 upbeat 电子乐。Tycho 遇 Bloomberg 开场曲。
在高亮处构建，在客户故事处变暖，在挑战处变柔和，在结尾处达到顶峰。

---

SCENE 1 — A-ROLL（8s）
[虚拟形象居中画面，充满活力，微微前倾]
VOICEOVER："一月是破纪录的一个月。收购、收入和
产品速度都创下新高。以下是全貌。"
下方三分之一滑入："公司名称 | 2026 年 1 月" 白色在蓝色条上。
网格擦除。

SCENE 2 — FULL SCREEN B-ROLL（12s）
[无虚拟形象——仅运动图形]
VOICEOVER："一百八十五万注册——较上月增长
百分之二十八。两百一十二万新订阅收入。两者都是历史
新高。"
LAYER 1：深色 #1a1a1a 背景，细网格线以 8% 不透明度脉动。
LAYER 2："1.85M" 从左侧猛击进入，白色 Bold 140pt。"SIGNUPS" 打字到
电蓝色 32pt 大写。"+28% MoM" 以琥珀色出现。
LAYER 3：三个统计卡片从右上角层叠，0.3s 交错：
         "$2.12M 新收入" — "$3.4M 商业 ARR" — "$3M Pro ARR。"
         每个数字从 0 计数。
LAYER 4：底部滚动条滚动："非品牌搜索 +36% • 品牌展示次数 920 万
         • 每周订阅 +20.5%"
LAYER 5：网格线在 "1.85M" 猛击时向外波纹。统计卡片后面的
         对角琥珀色条。
硬切。

SCENE 3 — FULL SCREEN B-ROLL（12s）
[无虚拟形象——仅运动图形]
VOICEOVER："拉远镜头。十二个月前——五千四百万 ARR。今天——
一亿四千一百万。一年内近三倍。"
LAYER 1：深色背景，微妙的网格向上滚动。
LAYER 2：动画折线图从左到右自行绘制。Y 轴：$50M 到 $150M。
         最终点 "$140.84M" 琥珀色发光并脉动。
LAYER 3：里程碑注释在关键数据点浮动进入。
LAYER 4：下方第二个更小的图表——"付费视频" 从 91 万到 297 万，相同风格。
LAYER 5：细网格线向最终数据点汇聚。扫描线扫过。
网格擦除。

SCENE 4 — A-ROLL（8s）
[虚拟形象居中画面，温暖语调，真诚微笑]
VOICEOVER："但数字只说明了一半故事。另一半是
构建在平台上的人们。"
下方三分之一："客户聚焦"

SCENE 5 — FULL SCREEN B-ROLL（12s）
[无虚拟形象——暖色调色板]
VOICEOVER："一个完全在平台上构建的 AI 角色。二十分钟
每个视频。两百五十万 Instagram 粉丝。创作者的准则：
用技术服务信息，而不是用它来分散注意力。"
LAYER 1：深色背景，低不透明度的暖琥珀色网格线。
LAYER 2："角色名称" 大号白色，中上位置，80pt。
LAYER 3：统计从右侧层叠："250 万粉丝" 琥珀色计数 —
         "20 分钟/视频" — "7 倍更快。" 每个是一个发光节点。
LAYER 4：引用卡片滑入："用技术服务信息，而不是
         用它来分散注意力。" 逐词打字到。
LAYER 5：暖光绽放。网格线柔化变成弧形。
网格擦除。

SCENE 6 — A-ROLL（10s）
[虚拟形象居中画面，严肃/坦诚]
VOICEOVER："现在是诚实的部分。自然流量驱动百分之六十五的
订阅，而且它波动很大。非品牌流量上周下降了百分之十六。
我们已经重建了归因模型，正在投资 SEO。"
下方三分之一："挑战"

SCENE 7 — A-ROLL（7s）
[虚拟形象居中画面，能量提升，直接眼神接触]
VOICEOVER："五千四百万到一亿四千一百万，十二个月。每月三百万
付费视频。一月设定了标准——现在我们提升它。"
结束卡：Logo 居中，蓝光淡入。网格线汇聚。音乐达到顶峰。

---

NARRATION STYLE：CEO 能量——信念由数据支持。在高亮处快速。
在客户故事处温暖。在挑战处坦诚。以前行动力结束。
```

## 即用模板

### 科技新闻简报
```
FORMAT：75 秒高能科技简报。风格：Bloomberg 遇 Vice。

AVATAR：[主持人在多显示器工位，科技休闲装。
描述服装、显示器内容、桌面物品、灯光。]

STYLE — DECONSTRUCTED (Brody)：深灰色 #1a1a1a，锈橙色 #D4501E。
字体带角度、重叠。颗粒质感。粉碎剪接过渡。

CRITICAL ON-SCREEN TEXT：
- [列出必须出现的每个统计、引用、账号]

SCENE 1 — A-ROLL（8s）：以能量开场。说明正在发生的事情。
SCENE 2 — B-ROLL（12s）：带分层视觉的第一个故事（L1-L5）。
SCENE 3 — A-ROLL + OVERLAY（10s）：第二个故事，分屏。
SCENE 4 — B-ROLL（10s）：第三个故事或戏剧性数据点。
SCENE 5 — A-ROLL（8s）：总结和前瞻。
```

### 产品对比
```
FORMAT：60 秒对比。[产品 A] vs [产品 B]。数据驱动。

AVATAR：[主持人在评测工作室。桌子上两个产品都可见。]

STYLE — DIGITAL GRID (Crouwel)：深色 #0a0a0a，青色 #00D4FF 和琥珀色 #FFB800。
双色编码：青色 = 产品 A，琥珀色 = 产品 B。等宽字体。

CRITICAL ON-SCREEN TEXT：
- [每个产品的关键统计]
- [定价、功能、差异化因素]

使用分割帧 B-roll：产品 A 左侧，产品 B 右侧。
```
