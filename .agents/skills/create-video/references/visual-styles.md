# 视觉风格库——20 种风格

用于 Video Agent 提示的命名视觉风格。每种风格灵感来自真实的设计师。按情绪强度排序。

**选择风格：** 先匹配情绪，再匹配内容。问：*「观众应该有什么感觉？」*

**使用风格：** 将风格块复制到提示的 STYLE 部分。使用视觉语言规则——不要注入示例 B-roll 场景（它们会混淆代理）。

**自定义风格：** 这些是示例。通过组合元素、参考其他设计师、艺术运动或文化美学来创建你自己的风格。模式：**命名风格 + 设计师参考 + 调色板 + 排版 + 动效规则 + 过渡。**

## 1. Soft Signal — Stefan Sagmeister

**情绪：** 亲密、温暖 | **最适合：** 个人故事、健康、反思

- 温暖琥珀色和奶油色，配灰玫瑰色、鼠尾草绿、蜜金色强调色
- 手写风格文本叠加——个性化、小写、精致
- 特写画面：手、脸、纹理。微距镜头感
- 缓慢漂移和浮动，从不突然。柔和溶解，温暖漏光

```
STYLE — SOFT SIGNAL (Sagmeister)：温暖琥珀/奶油色，灰玫瑰色，鼠尾草绿。
手写风格文本。特写画面。缓慢漂移和浮动。
柔和溶解带温暖漏光。
```

## 2. Warm Grain — Olle Eksell

**情绪：** 有机、友好 | **最适合：** 环境、可持续性、社区

- 大地色调：赭色、森林绿、陶土色、奶油色、柔棕色
- 圆角无衬线字体。有机圆润构图——无角度
- 16mm 胶片颗粒，略微去饱和。天然纹理：木材、亚麻、石材
- 温和擦除、柔和剪接、从容不迫

```
STYLE — WARM GRAIN (Eksell)：大地色调——赭色、森林绿、陶土色、奶油色。
有机圆润构图。16mm 胶片颗粒。圆角无衬线字体。
温和擦除和柔和剪接。
```

## 3. Quiet Drama — Satyajit Ray

**情绪：** 人文、沉思 | **最适合：** 简介、传记、文化

- 柔和温暖：深褐色、深棕色、柔金色、米白色、炭色
- 干净衬线字体，精心放置。肖像画面
- 强烈的单光源对比：窗光、单盏灯
- 从容的节奏，较长的保持。缓慢淡出到黑色

```
STYLE — QUIET DRAMA (Ray)：柔和温暖——深褐色、深棕色、柔金色。
肖像画面。干净衬线。强烈的单光源对比。
缓慢淡出到黑色。
```

## 4. Heritage Reel — Cassandre

**情绪：** 怀旧、复古 | **最适合：** 历史、回顾、品牌起源

- 褪色金色、深酒红色、海军蓝、奶油色、深褐色洗色
- 优雅居中衬线，如经典电影标题卡
- 暗角、柔化边缘。胶片颗粒、轻微划痕、温和抖动
- 虹膜擦除、胶片卷轴闪烁

```
STYLE — HERITAGE REEL (Cassandre)：褪色金色、酒红色、海军蓝、深褐色洗色。
优雅居中衬线。暗角和老化胶片颗粒。
虹膜擦除过渡。
```

## 6. Swiss Pulse — Josef Müller-Brockmann

**情绪：** 冷静、精确 | **最适合：** 数据密集、分析型、金融、指标

- 黑色 (#1a1a1a)、白色、一种强调色：电蓝色 (#0066FF)
- Helvetica Bold 标题、Regular 标签。数字**大号**（80-120pt）
- 网格锁定构图。每个元素卡入 12 列网格
- 动画计数器**从 0 计数**。关键时刻的对角线构图
- 网格擦除、硬切。无溶解

```
STYLE — SWISS PULSE (Müller-Brockmann)：黑色/白色 + 电蓝色 #0066FF。
网格锁定。Helvetica Bold。动画计数器。对角线强调。
网格擦除过渡。
```

## 7. Geometric Bold — Ikko Tanaka

**情绪：** 极简、优雅 | **最适合：** 简洁生活方式、文化、视觉散文、品牌简介

- 每帧最多 3 种纯色——无渐变
- 粗体干净字体作为主要视觉元素
- 不对称构图，60% 负空间最小。单个焦点
- 在节拍上干净剪接，无特效

```
STYLE — GEOMETRIC BOLD (Tanaka)：每帧最多 3 种纯色。
60% 负空间。粗体字体为主要元素。
单个焦点。在节拍上干净剪接。
```

## 8. Velvet Standard — Massimo Vignelli

**情绪：** 高端、永恒 | **最适合：** 奢侈品、投资者更新、主题演讲、产品展示

- 黑色、白色、一种丰富强调色：深海军蓝 (#1a237e) 或金色 (#c9a84c)
- 细无衬线，全大写，宽间距
- 慷慨的负空间。对称、居中、建筑精度
- 缓慢、从容。顺序揭示。优雅交叉溶解

```
STYLE — VELVET STANDARD (Vignelli)：黑色、白色、一种强调色：金色 #c9a84c。
细全大写，宽间距。慷慨的负空间。
缓慢优雅交叉溶解。
```

## 最终最佳实践

### 风格表现（来自 40+ 个视频）

| 排名 | 风格 | 优势 |
|------|-------|----------|
| 1 | Deconstructed (Brody) | 在所有主题中最可靠 |
| 2 | Swiss Pulse (Müller-Brockmann) | 最适合数据密集内容 |
| 3 | Digital Grid (Crouwel) | 科技主题表现出色 |
| 4 | Geometric Bold (Tanaka) | 优雅且多功能 |
| 5 | Maximalist Type (Scher) | 高能量，谨慎使用 |

### 按方法的时长

| 方法 | 平均时长 | 质量 |
|----------|-------------|---------|
| 自然故事板 + 自定义虚拟形象 | ~106s | 最好 |
| 自然故事板，无自定义虚拟形象 | ~69s | 好 |
| 强制短场景 + 自定义虚拟形象 | ~71s | 混合 |
| 布局语言提示 | ~48s | 差 |

## 质量检查清单

- [ ] 论文驱动——故事，而不是要点
- [ ] 风格命名包含颜色、排版、动效、过渡（参见 [visual-styles.md](visual-styles.md)）
- [ ] 虚拟形象有主题服装 + 品牌环境（60-100 词）
- [ ] 关键文本列出——每个统计数据、引用、标签
- [ ] 场景类型轮换——从未 3+ 相同类型。至少 2 个 B-roll 场景
- [ ] 每个场景有配音——包括 B-roll
- [ ] B-roll 场景有 4+ 层，每个元素有动效动词
- [ ] B-roll 场景为 10-15 秒（从不 ≤5s）
- [ ] 讨论公司时出现品牌 Logo
- [ ] 每个元素都动——无静态帧
