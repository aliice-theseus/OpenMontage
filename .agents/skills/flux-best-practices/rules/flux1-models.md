# FLUX.1 模型系列

> **提示：** FLUX.2 模型是最新一代，推荐用于大多数用例。FLUX.1 模型仍然可用于特定需求。

FLUX.1 模型及其专业能力指南。

## 模型概述

| 模型                 | 用途         | 说明                              |
| -------------------- | ------------ | --------------------------------- |
| FLUX1.1 [pro]        | 文生图       | FLUX.2 [pro] 提供更好的结果         |
| FLUX.1 Kontext       | 图生图       | 推荐使用 FLUX.2 配合参考图片        |
| FLUX.1 Kontext Max   | 图生图       | 推荐使用 FLUX.2 [max] 配合参考图片  |
| FLUX.1 Fill          | 图像修复     | 适用于特定的修复任务               |

## FLUX1.1 [pro]

快速可靠的文生图生成。

### 特性
- 强提示词遵循能力
- 生产级架构
- 一致、可靠的结果
- 可扩展处理大批量
- 定价：每张图片 $0.04

### 提示词风格

标准描述性提示词，带有明确的主体和风格描述。

### 示例提示词
```
一只金毛幼犬在秋叶中玩耍，温暖的午后阳光，
浅景深散景背景，欢快的表情，专业宠物摄影风格
```

## FLUX.1 Kontext - 图像编辑

> **建议：** 使用 FLUX.2 模型配合参考图片可获得更好的编辑效果。

上下文感知的图像到图像编辑模型，用于变换和修改。

### 特性
- 理解图像上下文
- 保留未编辑区域
- 风格迁移能力
- 物体修改
- 基础到复杂的变换

### 提示词策略

#### 基础编辑
简单、直接的指令效果最佳：

```
将汽车颜色改为红色
```

```
让天空变成日落橙色和粉色
```

#### 受控编辑
明确说明要保留的内容：

```
将场景改为夜晚，同时保持完全相同的构图和绘画的艺术风格
```

#### 复杂变换
对于戏剧性的变化，具体说明保留内容：

```
将现代办公室改造成维多利亚图书馆，保持相同的家具布置。
保持窗户位置和整体房间比例不变。
```

#### 风格迁移
参考特定的艺术运动：

```
将这张照片转换为包豪斯艺术风格，几何形状和原色，
保持原始构图和主体位置
```

#### 文字编辑
描述文字位置和集成：

```
在窗户中添加"OPEN"文字作为霓虹灯牌，红色发光字母，
在玻璃上有轻微反射，与夜间氛围相匹配
```

### Kontext 使用技巧
- 明确说明什么不应该改变
- 从简单的编辑开始，逐步增加复杂度
- 在需要时指定风格保留
- 用于增量优化

## FLUX.1 Kontext Max

用于复杂构图的高级多参考编辑。

### 特性
- 处理最多 10 张参考图片
- 跨参考的最佳编辑一致性
- 复杂场景构图
- 角色一致性保持
- 频率限制：6 个并发请求

### 多参考提示词

#### 自然语言参考
自然地描述图片之间的关系：

```
图片 1 中的人坐在图片 2 的咖啡馆里，
穿着图片 3 的衣服，使用图片 4 的光照风格
```

#### 显式索引
按编号精确引用图片：

```
将图片 1 中人物的上半部分替换为图片 2 的服装，
保持姿势和背景不变
```

### Kontext Max 使用技巧
- 仔细规划你的参考图片
- 使用自然语言描述关系
- 指定哪些元素来自哪些图片
- 利用它实现跨场景的角色一致性

## FLUX.1 Fill - 图像修复

专门用于物体移除和区域补全的工具。

### 特性
- 干净地移除物体
- 智能背景补全
- 纹理感知填充
- 无缝融合

### 使用场景
- 从照片中移除不需要的物体
- 补全部分图片
- 替换特定区域
- 清理图像伪影

### Fill 提示词

描述蒙版区域应该填充什么：

```
用砖墙纹理和常春藤的延续来填充
```

```

用匹配的海浪和沙滩来补全
```

### Fill 使用技巧
- 提供周围区域的上下文
- 指定纹理和图案的延续
- 描述光线一致性
- 用于清理和移除任务
