# 动作场面导演

把动作写成可拍、可生成、可剪辑的节拍，不要只堆招式名称。

## 核心流程

1. 确定动作戏的叙事任务、胜负关系、参与者和空间限制。
2. 为每个动作节拍写完整因果链：`意图 → 蓄力 → 出招 → 接触/落空 → 反应 → 恢复`。
3. 将连招拆成镜头：一个镜头聚焦一个主要动作节拍；用剪辑完成连续招式。
4. 明确重量、重心、惯性、受击方向、环境反馈和疲劳变化。
5. 选择一个动作流派，并使节奏、镜头、光影和声音共同服务该流派。
6. 运行安全与连续性检查，再把节拍交给视频生成或角色动画工具。

## 必须写出的信息

- 区分每个参与者，明确谁发起、谁应对、谁反击。
- 按时间顺序描述动作，不要把多个并发动作塞进一个从句。
- 至少覆盖“蓄力—出招—反应”；受击反应必须与来力方向一致。
- 写出重心转移、冲量延续和收势；大动作后允许踉跄或恢复。
- 用尘土、水花、碎屑、家具位移或衣料摆动表现冲击，避免依赖伤害特写。
- 长动作场面逐渐增加喘息、迟缓和防守变形，形成疲劳曲线。

## 按规模设计

- 单人：限制为 2–3 个连续节拍，加入环境交互和明确镜头运动。
- 双人：写成 `A 出招 → B 应对 → B 反击 → A 反应` 的闭环。
- 群战：锁定主角和一个前景对手；背景人群只提供压力与层次，不逐人编排。

## 镜头与剪辑

- 关键一击使用预备、接触和贯穿反应三段式。
- 仅在关键接触点使用升格、速度渐变、冲击帧或轻微镜震。
- 纪实动作可用近身手持；武侠可用跟拍和局部升格；竞技可用环绕与规则视角。
- 保留静止、对峙和恢复节拍。全程高速会削弱高潮。
- 在 `scene_plan` 阶段拆镜，在 `assets` 阶段生成单镜头提示，在 `edit` 阶段重建完整攻防节奏。

## 安全约束

- 将目标定义为风格化武打、竞技或虚构动作，不渲染血腥伤害细节。
- 对武器保持电影化距离，避免器械伤害特写。
- 不设计未成年人参与对抗性打斗。
- 采用 `stylized action, no gore` 等非血腥约束，并遵守目标平台规范。

## 交付检查

- 每个动作是否有原因、接触结果和可见反应？
- 方向、站位、道具和角色身份是否跨镜头连续？
- 是否一镜一主要节拍，且镜头运动没有掩盖动作？
- 环境是否参与表现重量？
- 风格是否统一，高潮是否有节奏对比？
- 是否避免血腥、未成年人对抗和伤害猎奇？
