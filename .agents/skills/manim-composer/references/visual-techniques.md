# 数学动画视觉技巧

解释数学概念的有效可视化模式。

## 核心原则

### 1. 渐进式披露
永远不要一次性展示所有内容。逐步构建复杂性。

**差劲：** 立即显示完整方程
**好：** 逐项构建方程，解释每个部分

```
场景流程：
1. 展示简单情况：f(x) = x²
2. 增加复杂度：f(x) = ax²
3. 完整形式：f(x) = ax² + bx + c
```

### 2. 变换而非替换
尽可能将对象变形为新形式，而不是淡出/淡入。

**差劲：** FadeOut(equation1), FadeIn(equation2)
**好：** TransformMatchingTex(equation1, equation2)

这保持了视觉连续性，并显示了形式之间的关系。

### 3. 颜色即含义
在整个视频中一致地使用颜色编码含义。

**模式：**
- 输入/给定值：蓝色
- 输出/结果：绿色
- 正在讨论的关键术语：黄色高亮
- 错误/负面：红色
- 中性/辅助：白色/灰色

### 4. 空间关系
位置编码关系：
- 从左到右：变换、时间、因果
- 从上到下：层次、推导
- 中心：关注焦点
- 边缘：上下文、参考

## 动画技巧

### 高亮与聚焦

**Indicate** - 短暂闪烁以吸引注意力
```python
self.play(Indicate(term))
```

**Circumscribe** - 在重要元素周围画圈
```python
self.play(Circumscribe(equation, color=YELLOW))
```

**FlashAround** - 揭示时戏剧性闪光
```python
self.play(FlashAround(result))
```

### 方程操作

**隔离项** - 给特定部分着色或移动
```python
equation.set_color_by_tex("x", BLUE)
```

**逐步推导** - 展示每个代数步骤
```python
step1 = MathTex(r"2x + 4 = 10")
step2 = MathTex(r"2x = 6")
step3 = MathTex(r"x = 3")
# 在步骤之间用对齐变换
```

**代入** - 显示数值被代入
```python

```

### 几何直觉

**坐标系** - 始终标注坐标轴
```python
axes = Axes(x_range=[-3, 3], y_range=[-2, 2])
labels = axes.get_axis_labels(x_label="x", y_label="f(x)")
```

**轨迹路径** - 显示点的移动路径
```python
trace = TracedPath(dot.get_center, stroke_color=YELLOW)
```

**面积可视化** - 用于积分、求和
```python
area = axes.get_area(graph, x_range=[a, b], color=BLUE, opacity=0.5)
```

## 常见视觉隐喻

### 向量作为箭头
- 位置向量：从原点出发的箭头
- 加法：首尾相接
- 缩放：拉伸/收缩

### 函数作为机器
- 输入从一侧进入
- 变换发生
- 输出从另一侧出来

### 矩阵作为变换
- 显示网格被变换
- 追踪基向量的去向
- 强调行列式为面积缩放

### 导数作为斜率
- 切线接触曲线
- 放大显示局部线性
- 动画显示斜率随点移动而变化

### 积分作为累积
- 黎曼和的矩形
- 宽度→0 的动画
- 曲线下的面积填充

## 时间指南

| 动作               | 典型时长 |
|--------------------|----------|
| 简单形状创建       | 0.5-1s   |
| 文本/方程书写      | 1-2s     |
| 变换               | 1-2s     |
| 镜头移动           | 2-3s     |
| 吸收性暂停         | 0.5-1s   |
| 复杂动画           | 2-4s     |

### 节奏模式
快-快-慢-快-快-慢

快速动画用于设置，关键见解时放慢速度。
