# 运镜导演

先决定镜头要让观众知道或感受什么，再选择相机运动。不要为炫技而移动。

## 单镜头公式

按以下顺序规划：

`[景别] + [一种主相机运动] + [速度] + [被锚定的主体与动作] + [环境/氛围]`

把相机运动和速度放在提示前段。每个镜头只保留一种主运动；焦点变化、轻微呼吸或前景穿越只能作为兼容的次级行为。

## 决策流程

1. 写一句镜头任务：交代环境、推进叙事、放大情绪、制造高潮或完成转场。
2. 选择景别及其在镜头内是否变化。
3. 选择机位高度、角度和稳定方式。
4. 选择一种主运动，并写明方向、速度、起点和终点。
5. 锚定主体，说明相机相对主体的位置关系。
6. 检查运动幅度是否适合片段时长和模型能力。
7. 对图生视频检查首帧是否支持该运动，并添加稳定性负面约束。

## 任务到运镜

- 交代世界：大远景/远景 + 航拍、升起或缓慢下降。
- 推进叙事：中景 + 平行跟拍、背后跟拍或稳定器缓移。
- 放大情绪：近景/特写 + 缓慢推进或克制手持。
- 揭示反转：从细节缓慢拉开，或横移后揭示画外信息。
- 制造高潮：升格、速度渐变、希区柯克变焦；只在关键节点使用。
- 转场：甩镜或穿前景，但必须有明确落点和匹配方向。
- 关键信息：保留固定机位；静止也是有意的镜头选择。

## 景别节奏

常规推进：`EWS 建立 → MS 叙事 → CU 情绪 → ECU 爆点`。

悬念可反向：先用 ECU 展示无法解释的细节，再拉开揭示空间。不要让整条片子停留在同一景别。

## 兼容与风险

- 不同时写 `push in` 和 `pull back` 等矛盾主运动。
- 不省略速度词；使用 `slow`, `steady`, `fast` 等明确节奏。
- 大幅环绕、FPV 或穿越需要足够时长；短片段应减小幅度。
- 图生视频中，首帧没有侧向空间时不要要求大幅横移；主体贴边时不要向该方向跟拍。
- 强运镜会破坏中心对称和精确构图，必要时改为静态或微推。
- 使用负面约束 `jittery camera, warping, morphing, distorted motion`，但以提供商支持为准。

## 阶段应用

- `scene_plan`：记录景别、机位、主运动、速度、主体锚定、起止构图和风险。
- `scene_sketch/key_visual`：验证首帧构图能否承载计划运动。
- `assets`：把镜头规范翻译成提供商适配的提示，不与控制面板参数冲突。
- `edit`：建立远中近节奏，保留静止镜头，避免连续高强度运镜。
- `review`：检查漂移、丢主体、方向错误、幅度过大和运动冲突。

## 交付检查

- 每个镜头是否只有一种主运动？
- 是否写明速度、方向、起点、终点和主体锚点？
- 运镜是否服务叙事任务和情绪？
- 首帧、景别和可用时长是否支持该运动？
- 是否保留静止镜头并形成景别节奏？
- 是否排除抖动、形变和运动漂移？
