# Video Agent 提示示例

## 完整示例：从简要到生产提示

### 输入简要

```
主题：某 SaaS 初创公司的月度公司报告
关键数据：$141M ARR（从 $54M 增长），1.85M 注册量（+28%），每月 3M 付费视频
客户故事：创作者构建了 AI 角色，2.5M 粉丝，每视频 20 分钟
挑战：自然流量波动大，上周 -16%
时长：约 90 秒
基调：自信 CEO，数据支撑
```

### 输出提示

```
FORMAT：彭博风格公司报告。90秒。快节奏、数据密集。
破纪录的月份。自豪但分析性强。

TONE：自信、直接、数据支撑。亮点用数字有力表达。
客户故事是情感核心。挑战是诚实的——不加修饰。

AVATAR：男士穿着简单的黑色圆领T恤，站在现代玻璃墙办公室中，
沐浴在黄金时刻的阳光里。他身后，壁挂式显示器显示公司标志
在柔和的蓝光中。右侧的显示器显示向上趋势的仪表板图表。
旁边的桌子：笔记本电脑、半杯白咖啡、散落的便利贴。
午后温暖阳光透过落地窗，长阴影投射在抛光混凝土地面上。
极简、专注的初创公司总部。

STYLE — SWISS PULSE (Müller-Brockmann)：网格锁定构图。黑色 (#1a1a1a)、
白色、电光蓝 (#0066FF)、暖琥珀色 (#FF9500) 用于纪录。Helvetica Bold
标题、Regular 标签。数字 大。动画计数器从 0 向上计数。
关键时刻对角构图。网格擦除过渡。无溶解。

CRITICAL ON-SCREEN TEXT（字面显示）：
- "1.85M 注册量 — 环比增长 28%"
- "$2.12M 新订阅收入"
- "$54M → $141M ARR"
- "2.5M 粉丝" 和 "20 分钟/视频"
- 引用："Use technology to serve the message, not distract from it."
- "自然流量：占订阅量的 65% — 波动"

MUSIC：节奏驱动的电子乐。Tycho 遇见彭博开场主题曲。
在亮点时增强，客户故事时温暖，挑战时柔和，结尾时达到高峰。

---

SCENE 1 — A-ROLL (8s)
[虚拟角色居中，能量充沛，微微前倾]
VOICEOVER："January was a record month. New highs across acquisition, revenue,
and product velocity. Here's the full picture."
Lower-third SLIDES in："COMPANY NAME | JANUARY 2026" 白色在蓝色栏上。
网格擦除。

SCENE 2 — FULL SCREEN B-ROLL (12s)
[无虚拟角色 — 仅动态图形]
VOICEOVER："One-point-eight-five million signups — twenty-eight percent month
over month. Two-point-one-two million in new subscription revenue. Both all-time highs."
LAYER 1：深色 #1a1a1a 背景，网格线以 8% 不透明度脉动。
LAYER 2："1.85M" 从左侧猛击进来，白色 Bold 140磅。"SIGNUPS" 在上面打出
电光蓝 32磅 大写。"+28% MoM" 以琥珀色显示。
LAYER 3：三个统计卡从右上角级联，交错 0.3秒：
"$2.12M New Revenue" — "$3.4M Business ARR" — "$3M Pro ARR"。
每个数字从 0 向上计数。
LAYER 4：底部滚动条滚动："Non-brand search +36% • Brand impressions 9.2M • Weekly subs +20.5%"
LAYER 5：网格线在 "1.85M" 猛击时向外波纹扩散。统计卡后的对角琥珀色条。
硬切。

SCENE 3 — FULL SCREEN B-ROLL (12s)
[无虚拟角色 — 仅动态图形]
VOICEOVER："Zoom out. Twelve months ago — fifty-four million ARR. Today —
one hundred forty-one million. Nearly three X in a single year."
LAYER 1：深色背景，网格线向上滚动。
LAYER 2：动画折线图从左到右绘制自身。Y轴：$50M 到 $150M。
终点 "$140.84M" 琥珀色发光并脉冲。
LAYER 3：里程碑注释在关键数据点处浮入。
LAYER 4：下方第二个更小的图表——"Paid Videos" 0.91M 到 2.97M，相同风格。
LAYER 5：细网格线向最终数据点汇聚。扫描线扫过。
网格擦除。

SCENE 4 — A-ROLL (8s)
[虚拟角色居中，温暖语气，真诚微笑]
VOICEOVER："But the numbers only tell half the story. The other half is the
people building on the platform."
Lower-third："客户聚焦"

SCENE 5 — FULL SCREEN B-ROLL (12s)
[无虚拟角色 — 温暖调色板]
VOICEOVER："An AI character built entirely on the platform. Twenty minutes
per video. Two-point-five million Instagram followers. The creator's principle:
use technology to serve the message, not distract from it."
LAYER 1：深色背景配暖琥珀色网格线，低不透明度。
LAYER 2："角色名称" 大号白色，顶部居中，80磅。
LAYER 3：统计数据从右侧级联："2.5M Followers" 在琥珀色中向上计数 —
"20 min/video" — "7x Faster." 每个都是一个发光的节点。
LAYER 4：引用卡片滑起："Use technology to serve the message, not
distract from it." 逐词打出。
LAYER 5：暖光绽放。网格线柔化为曲线弧。
网格擦除。

SCENE 6 — A-ROLL (10s)
[虚拟角色居中，严肃/坦诚]
VOICEOVER："Now the honest part. Organic drives sixty-five percent of
subscriptions and it's volatile. Non-brand traffic dropped sixteen percent
last week. We've rebuilt attribution and we're investing in SEO."
Lower-third："Challenges"

SCENE 7 — A-ROLL (7s)
[虚拟角色居中，能量回升，直接眼神交流]
VOICEOVER："Fifty-four million to one-forty-one in twelve months. Three million
paid videos a month. January set the bar — now we raise it."
结束卡片：标志居中，蓝光淡入。网格线汇聚。音乐达到高峰。

---

NARRATION STYLE：CEO能量——以数据支撑的信念。亮点快速。
客户故事温暖。挑战坦诚。以向前势头结束。
```

## 即用模板

### 科技新闻简报
```
FORMAT：75秒高能量科技简报。像是：Bloomberg 遇上 Vice。

AVATAR：[演示者穿着科技休闲装在多显示器工作站。
描述服装、显示器内容、桌上物品、灯光。]

STYLE — DECONSTRUCTED (Brody)：深灰 #1a1a1a、锈橙 #D4501E。
类型在角度上、重叠。砂砾纹理。猛切过渡。

CRITICAL ON-SCREEN TEXT：
- [列出每个必须出现的统计、引用、账号]

SCENE 1 — A-ROLL (8s)：用能量钩住。陈述正在发生的事情。
SCENE 2 — B-ROLL (12s)：带分层视觉的第一个故事（L1-L5）。
SCENE 3 — A-ROLL + OVERLAY (10s)：第二个故事，分屏。
SCENE 4 — B-ROLL (10s)：第三个故事或戏剧性数据点。
SCENE 5 — A-ROLL (8s)：总结和向前看。
```

### 产品比较
```
FORMAT：60秒比较。[产品A] vs [产品B]。数据驱动。

AVATAR：[演示者在评测工作室。桌上两个产品都可见。]

STYLE — DIGITAL GRID (Crouwel)：深色 #0a0a0a、青色 #00D4FF 和琥珀色 #FFB800。
双色编码：青色 = 产品A，琥珀色 = 产品B。等宽字体。

CRITICAL ON-SCREEN TEXT：
- [每个产品的关键统计数据]
- [定价、功能、差异化因素]

使用分屏 B-roll：产品A 左，产品B 右。
```

### 战略演示
```
FORMAT：90秒战略简报。Bloomberg 遇上董事会会议。

AVATAR：[高管穿着西装外套内搭T恤。带白板框架的会议室。]

STYLE — SWISS PULSE (Müller-Brockmann)：黑/白 + 蓝 #0066FF。
网格锁定。Helvetica。动画计数器。网格擦除过渡。

CRITICAL ON-SCREEN TEXT：
- [框架标签、象限标签、关键引用]

视觉化构建框架：绘制坐标轴、标绘位置、动画化标签。
```

### 社交广告（30秒）
```
FORMAT：30秒社交广告。最大能量。竖屏 9:16。

AVATAR：[创作者风格演示者。环形灯、彩色背景。]

STYLE — CARNIVAL SURGE (Lins)：热粉、黄、蓝绿。拼贴分层。
文本巨大在角度上。五彩纸屑。猛切。

三个场景：钩子 (8s) → 价值主张 (12s) → 行动号召 (10s)。
文本占据每帧 50-80%。数字猛击。
```

### 高级报告
```
FORMAT：120秒投资级报告。低调权威。

AVATAR：[合身美利奴毛衣。建筑感房间，漫射自然光。]

STYLE — VELVET STANDARD (Vignelli)：黑、白、金 #c9a84c。
细全大写，宽字距。充裕留白。
慢交叉溶解。数字带着重量淡入。
```
