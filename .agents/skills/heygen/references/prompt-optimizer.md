# Video Agent 提示优化器

为 HeyGen Video Agent API 编写有效提示。基于 40+ 个已制作视频的模式。

**核心洞察：Video Agent 是一个 HTML 解释器。** 它原生渲染布局、排版和结构化内容。将 B-roll 描述为带动作动词的分层文本动态图形（"猛地切入"、"在上面打字"、"向上计数"）——而不是布局规格（"左上角，48磅"）。

## 工作流：从简要到提示

1. **提取数据**——研究主题：网络搜索、API、内部文档。收集真实引用、统计数据、账号
2. **综合论点**——不是列表。而是一个故事。*"X 正在发生因为 Y —— 这是证据。"* 分为3-5个主题，有叙事弧线
3. **选择风格**——先匹配情绪，后匹配内容。问：*"观众应该感受到什么？"* 详见 [visual-styles.md](visual-styles.md)
4. **设计虚拟角色**——与内容情感上下文相匹配的主题服装（见下方虚拟角色指南）
5. **提取关键文本**——列出每个必须字面显示的数字、引用、账号和标签
6. **分解为场景**——每场景一个概念。轮换场景类型。从不连续3个以上相同类型。至少2个纯B-roll场景
7. **编写配音**——配音中拼读数字（"一百八十五万"），屏幕上使用数字（"1.85M"）。每个场景包括B-roll都有旁白
8. **分层每个 B-roll 场景**——L1背景、L2主角、L3辅助、L4信息栏、L5效果。每个元素必须**动**
9. **添加音乐方向**——引用艺术家，描述能量弧线
10. **添加叙事风格**——如何表达：快/慢，哪里暂停，每段的情感基调

## 提示结构

每个生产质量提示遵循以下结构：

```
FORMAT:    什么类型的视频、多长、什么能量
TONE:      情感基调、参考
AVATAR:    详细的物理+环境描述（60-100字）
STYLE:     命名的美学风格，含颜色、排版、运动规则、过渡
CRITICAL ON-SCREEN TEXT:  必须出现的精确字符串
SCENE-BY-SCENE:  带配音和分层视觉的逐场景分解
MUSIC:     流派、参考艺术家、能量弧线
NARRATION STYLE:  如何表达配音
```

### FORMAT

```
FORMAT: 75秒高能量科技每日简报。想象：一个刚收到好消息的创作者。
FORMAT: 彭博风格战略简报。100-120秒。CEO演讲。
```

### TONE

```
TONE: 自信、直接、数据支撑。亮点有力。低点诚实——不加修饰。
TONE: 前卫、朋克技术评论。Vice News 遇上 The Face 杂志——原始、对抗。
```

### CRITICAL ON-SCREEN TEXT

列出每个必须在屏幕上出现的精确字符串。没有这个，agent 可能会总结、四舍五入数字或改写引用。

```
CRITICAL ON-SCREEN TEXT（字面显示）：
- "$141M ARR — 历史新高"
- "1.85M 注册量 — 环比增长28%"
- 引用："Use technology to serve the message, not distract from it." — Shalev Hani
- "@username" — 精确的社交账号
```

### MUSIC & NARRATION

```
MUSIC: 驱动性电子乐，关键数字处重低音爆发。Run the Jewels 遇上科技主题演讲。
持续增强，仅在客户故事时柔和，结尾达到高峰。

NARRATION STYLE: 全程高能量。让数字 PUNCH（突显）——在重要数字前暂停，
然后有力表达。客户故事要温暖。结尾应感觉像麦克风掉落。
```

## 虚拟角色描述指南

**虚拟角色不是固定头像**——像电影角色一样为每个视频设计。思考服装设计师 + 布景设计师。

### 主题服装规则

虚拟角色的服装和环境必须与内容的情感和文化上下文匹配：

| 内容类型 | 虚拟角色设计 | 不要这样 |
|---|---|---|
| 中国新年 | 红色旗袍配金色刺绣，灯笼照亮的庭院 | "穿西装外套的记者" |
| 突发科技新闻 | 外景记者，被风吹乱的头发，耳机，城市天际线 | "在桌前的主播" |
| 睡眠科学 | 超大的奶油色针织衫，盘腿坐在床上，温暖的台灯 | "在实验室的分析师" |
| Reddit 社区 | 凌乱的桌子，显示器上的 Reddit 外星人，墙上的 upvote 箭头 | "在工作室的研究员" |

### 要指定什么

| 元素 | 弱 | 强 |
|---------|------|--------|
| 服装 | "商务休闲" | "黑色罗纹美利奴高领毛衣，高领框住下巴" |
| 环境 | "一间办公室" | "玻璃墙会议室。白板上有手绘层级金字塔" |
| 显示器内容 | "电脑屏幕" | "显示器显示滚动的绿色终端文本和红色安全警报" |
| 灯光 | "照明良好" | "左侧冷蓝显示器光，右侧暖琥珀色台灯" |

### 模板

```
AVATAR: [服装 — 面料、颜色、版型、配饰、姿态]。
[场景 — 特定道具、品牌标志、墙上有什么]。
[显示器/桌面 — 屏幕上可见内容、桌上的物品]。
[灯光 — 方向、色温]。[空间氛围]。
60-100字。3个以上内容相关道具。品牌元素可见。
```

## 场景类型

| 类型 | 格式 | 何时使用 |
|------|--------|-------------|
| **A-ROLL** | 虚拟角色对镜头说话 | 介绍、关键见解、行动号召、情感时刻 |
| **全屏 B-ROLL** | 无虚拟角色——仅动态图形 | 数据可视化、信息密集型内容 |
| **A-ROLL + 叠加** | 分屏：虚拟角色 + 内容 | 展示数据同时保持人情味 |

**必须轮换。** 从不连续3个以上相同类型。每个提示至少需要2个纯B-roll场景。

**每个场景都有配音。** 每个B-roll场景必须包含 `VOICEOVER:` 行。无声 B-roll = 损坏的视频。

### 场景结构

**A-ROLL：**
```
SCENE 1 — A-ROLL (10s)
[虚拟角色居中，兴奋，手势]
VOICEOVER: "此场景的精确脚本。"
Lower-third: "标题文本" 白色在蓝色栏上。
```

**带分层的 B-ROLL：**
```
SCENE 2 — FULL SCREEN B-ROLL (12s)
[无虚拟角色 — 仅动态图形]
VOICEOVER: "此场景的精确脚本。"
LAYER 1: 深色 #1a1a1a 背景，网格线轻轻脉动。
LAYER 2: "标题" 从左侧猛地切入，白色加粗 100磅，-5度旋转。
LAYER 3: 三个数据卡从右侧级联，交错 0.3秒。
LAYER 4: 底部信息栏滑入："持续滚动的支持文本。"
LAYER 5: 网格线从冲击点向外波纹扩散。
硬切。
```

**A-ROLL + 叠加：**
```
SCENE 3 — A-ROLL + OVERLAY (10s)
[分屏 — 虚拟角色左 35%。内容右 65%。不重叠。]
虚拟角色朝内容侧做手势。
VOICEOVER: "此场景的精确脚本。"
RIGHT SIDE: "标题" 青色 60磅。三个统计数据在下面向上计数。
```

在叠加场景之间交替虚拟角色出现的侧面。

## 视觉分层系统

将 B-roll 分为5个堆叠层次。这是动态图形场景最强大的技巧。

| 层次 | 用途 | 示例 |
|-------|---------|---------|
| **L1** | 背景 | 纹理表面、网格、渐变、色场 |
| **L2** | 主角内容 | 主导画面的主标题/数字 |
| **L3** | 辅助数据 | 卡片、统计、要点、次要信息 |
| **L4** | 信息栏 | 滚动条、标签、来源归属、引用 |
| **L5** | 效果 | 粒子、毛刺、网格动画、环境运动 |

每个 B-roll：4+ 层。每个叠加内容侧：3+ 层。**每个元素必须动。**

## 动作词汇

### 高能量
| 动词 | 示例 |
|------|---------|
| **SLAMS（猛击）** | `"$95M" 从左侧 -5度 猛击进来` |
| **CRASHES（撞击）** | `标题从右侧撞击进来，冲击时屏幕抖动` |
| **PUNCHES（冲击）** | `引用卡片从底部向上冲击` |
| **STAMPS（烙印）** | `数据块交错 0.4秒 烙印进来` |
| **SHATTERS（破碎）** | `文本在 1.5秒 后破碎，揭示下面的数字` |

### 中等能量
| 动词 | 示例 |
|------|---------|
| **CASCADE（级联）** | `三个卡片从顶部级联，交错 0.3秒` |
| **SLIDES（滑入）** | `信息栏从右侧滑入 — 持续滚动` |
| **DROPS（落下）** | `"TIER 1" 带着白色闪光落下` |
| **FILLS（填充）** | `进度条从 0% 填充到 90%，橙色` |
| **DRAWS（绘制）** | `图表线从左到右绘制自身` |

### 低能量
| 动词 | 示例 |
|------|---------|
| **types on（打字）** | `引用在斜体白色中逐词打出` |
| **fades in（淡入）** | `标志在中心淡入，停留 3秒` |
| **FLOATS（漂浮）** | `散景光球以不同速度漂浮穿过画面` |
| **morphs（变形）** | `数字从 17 变形为 18.9` |
| **COUNTS UP（向上计数）** | `"1.85M" 从 0 开始向上计数，琥珀色 96磅` |

## 过渡类型

| 过渡 | 能量 | 适合的风格 |
|------------|--------|---------------|
| Smash cut（猛切） | 激进 | Deconstructed、Maximalist、Carnival Surge |
| White flash frame（白色闪帧） | 冲击 | Deconstructed、Maximalist |
| Grid wipe（网格擦除） | 系统 | Swiss Pulse、Digital Grid |
| Hard cut（硬切） | 干净 | Swiss Pulse、Shadow Cut |
| Liquid dissolve（液体溶解） | 优雅 | Data Drift、Dream State |
| Slow cross-dissolve（慢交叉溶解） | 精致 | Velvet Standard |
| Pop cut / bounce（弹出/弹跳） | 有趣 | Play Mode、Carnival Surge |
| Snap cut（干脆切） | 紧急 | Red Wire、Contact Sheet |
| Soft dissolve（软溶解） | 温暖 | Soft Signal、Warm Grain、Quiet Drama |
| Iris wipe（虹膜擦除） | 怀旧 | Heritage Reel |

## 时间指南

| 内容类型 | 时长 |
|--------------|----------|
| 钩子/介绍（A-roll） | 6-10秒 |
| 数据密集型 B-roll | 10-15秒（绝不可 ≤5秒——会导致黑帧） |
| A-roll + 叠加 | 8-12秒 |
| 行动号召/结束（A-roll） | 6-8秒 |

**常见视频长度：** 社交短片：30-45秒（5-7场景）| 简报：60-75秒（7-9场景）| 深度内容：90-120秒（10-13场景）

**语速：** ~150字/分钟。计算：`字数 / 150 * 60 = 秒数`

## 什么不起作用

持续产生不良结果的模式：

**布局语言**——屏幕坐标导致空的/黑色 B-roll：
```
❌ "左上角：48磅 Helvetica 标题"
❌ "屏幕中央：坐标 (400, 300) 处显示"
✅ "135K" 从左侧猛击进来，白色 Impact 120磅，填充画面40%。
```

**命名艺术家没有规格**——"Ikko Tanaka 风格"对 Video Agent 毫无意义。翻译为具体规则：
```
❌ "使用 Ikko Tanaka 风格"
✅ "扁平色块，每帧最多3种颜色，60%留白，排版为主要元素"
```

**在提示中注入风格示例**——来自风格库的完整示例场景会混淆 agent。使用风格的**规则**而非示例场景。

**强制短 B-roll（≤5秒）**——太短无法渲染。每个测试过的5秒 B-roll 视频都有空的/黑色画面。使用10-15秒。

**内容是列表，不是故事**——"这里有5条推文"产生平淡的视频。始终综合：*"X 正在发生因为 Y —— 这是证据。"*

## 制作洞察

### 风格表现（来自40+视频）

| 排名 | 风格 | 优势 |
|------|-------|----------|
| 1 | Deconstructed（Brody） | 跨所有主题最可靠 |
| 2 | Swiss Pulse（Müller-Brockmann） | 数据密集型内容最佳 |
| 3 | Digital Grid（Crouwel） | 科技主题强劲 |
| 4 | Geometric Bold（Tanaka） | 优雅且多才多艺 |
| 5 | Maximalist Type（Scher） | 高能量，谨慎使用 |

### 按方法划分的时长

| 方法 | 平均时长 | 质量 |
|----------|-------------|---------|
| 自然故事板 + 自定义虚拟角色 | ~106秒 | 最佳 |
| 自然故事板，无自定义虚拟角色 | ~69秒 | 良好 |
| 强制短场景 + 自定义虚拟角色 | ~71秒 | 混合 |
| 布局语言提示 | ~48秒 | 差 |

## 质量检查清单

- [ ] 论点驱动——故事，不是要点
- [ ] 风格名称带颜色、排版、动作、过渡（详见 [visual-styles.md](visual-styles.md)）
- [ ] 虚拟角色有主题服装 + 品牌环境（60-100字）
- [ ] 关键文本列出——每个统计、引用、标签
- [ ] 场景轮换类型——从未 3+ 相同类型。至少 2 个 B-roll 场景
- [ ] 每个场景有 VOICEOVER——包括 B-roll
- [ ] B-roll 场景有 4+ 层，每个元素有动作动词
- [ ] B-roll 场景 10-15 秒（绝不可 ≤5 秒）
- [ ] 讨论公司时出现品牌标志
- [ ] 每个元素都动——无静态帧
