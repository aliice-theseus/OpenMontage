# 章节

本文件定义了所有章节、它们的排序、影响级别和描述。
章节 ID（括号内）是用于分组规则的文件名前缀。

---

## 1. 组件架构 (architecture)

**影响：** 高  
**描述：** 用于构建组件以避免属性泛滥和实现灵活组合的基本模式。

## 2. 状态管理 (state)

**影响：** 中等  
**描述：** 用于提升状态和管理组合组件间的共享上下文的模式。

## 3. 实现模式 (patterns)

**影响：** 中等  
**描述：** 实现复合组件和上下文提供者的具体技术。

## 4. React 19 API (react19)

**影响：** 中等  
**描述：** 仅 React 19+。不要使用 `forwardRef`；使用 `use()` 替代 `useContext()`。
