# ASR 关键词辉光

短语中的单词在"被读出"时视觉激活（辉光模糊 + 缩放），遵循攻击-保持-释放（类似 ASR）包络。在真实 ASR 管线中，这些时序来自词级转录数据；对于宣传视频，硬编码时序以控制强调节奏。包络在单词后留下微妙的"休息辉光"，创建最近强调的面包屑痕迹。

## 工作原理

每个单词有 `{ start, end }` 时间戳。在每帧，计算单词的包络值：

- **开始前** → 0（尚未）
- **开始 → 峰值** → 攻击（线性斜坡 0 → 1）
- **峰值 → 结束** → 保持（保持在 1）
- **结束 → 结束+释放** → 衰减（1 → restLevel，通常 0.25）
- **释放后** → restLevel（保持微妙高亮）

包络驱动 `textShadow` 模糊半径**和** `scale`。更高模糊 + 更大缩放 = "说话中"强调。

## 如何选择值

- **TIMINGS** — 逐词 `{ start, end }` 映射。每个 `.word` span 编写一个条目。
- **ATTACK_DUR** — 包络 0 → 1 的秒数
  - 范围：0.1-0.25 秒
- **RELEASE** — 包络 1 → REST_LEVEL 的衰减秒数
  - 范围：0.2-0.5 秒
- **REST_LEVEL** — 释放后保持的包络值
  - 范围：0.15-0.4（默认风格）；0.05-0.2（卡拉 OK 风格 — 更暗的休息）
- **MAX_BLUR** — 峰值 `text-shadow` 模糊半径（px）
  - 范围：15-25 px（默认风格）；30-45 px（卡拉 OK 风格）
- **MAX_SCALE_BOOST** — 峰值的附加缩放（例如 0.08 ⇒ 1.0 → 1.08）
  - 范围：0.03-0.10（默认风格）；0.15-0.25（卡拉 OK 风格）

## 关键原则

- **包络形状：攻击-保持-衰减-休息** — 单词后从不到零。休息级别（REST_LEVEL > 0）使刚说过的单词微妙高亮，创建注意力的"面包屑痕迹"。
- **品牌词获得更长的强调（1.5-2× 正常）** — 品牌是标题；让它保持。
- **每个单词 `display: inline-block`** — `transform` 应用于 `<span>` 所需。
- **MAX_BLUR 和 MAX_SCALE_BOOST 保持在其默认风格范围内，除非你承诺使用卡拉 OK** — 在默认和卡拉 OK 之间选择值会产生尴尬的"半响度"强调。
- **逐词 `text-shadow`**（而非 `box-shadow`）— text-shadow 是围绕字形的辉光，读作"说话强调。"Box-shadow 会围绕 inline-block 边界框（矩形）辉光。
- **单一驱动器，多单词 onUpdate** — 一个遍历所有单词的补间。不要为每个单词创建一个补间 — 在 60+ 单词时时间线变得笨重。
- **❗ 高潮停留 ≥1s** — 在最后一个词的强调后，组合继续 ≥1s。最后一个词**就是**标题节拍。
