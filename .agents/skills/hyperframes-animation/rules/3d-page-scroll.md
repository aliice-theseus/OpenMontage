# 3D 页面滚动

一个网页（或长内容）呈现为倾斜的 3D 卡片。弹簧缓动滚动揭示特定部分，而静态 3D 透视增加物理深度。

## 工作原理

两个独立变换组合：

1. **3D 倾斜** — 卡片上的静态 `rotateY` + `rotateX` 带 `perspective`。角度在场景期间**不**变化。
2. **滚动** — 卡片内部内容在裁剪容器内垂直平移（`translateY` / GSAP 中的 `y`），由 GSAP 补间驱动。通过 `ease: "power3.out"` 或 `"power4.out"` 实现弹簧样减速。

可选层：

3. **聚光灯叠加** — 一个径向渐变遮罩在滚动着陆后使除焦点区域外的一切变暗。用于将注意力吸引到一个部分。

## 关键原则

- **倾斜是静态的**，非动画化。卡片在整个场景保持其角度。
- **阴影方向匹配倾斜**：左倾卡片向右投射阴影（正 X 阴影偏移）。不匹配破坏 3D 幻觉。
- **页面内容是真实 HTML**，非截图。截图无法单独高亮或精确滚动到。
- **使用真实布局确定距离**：滚动目标距离来自实际的累积部分高度，而非估计的像素值。
- **聚光灯作为叠加**，不在 page-content 内部 — 叠加位于滚动内容上方并相对于卡片保持固定。
