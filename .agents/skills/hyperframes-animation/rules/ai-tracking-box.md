# AI 跟踪框

一个带有角标记（"L 形支架"）的边界框，跟随移动目标，模拟实时 AI 检测。位置和大小在正弦路径上振荡，模拟连续重新计算。传统上在暗背景上用"AI 检测黄"（`{detectionYellow}`）渲染，带置信度标签。

## 工作原理

- 框位置 `(x, y)` 和大小 `(w, h)` 从组合时间上的正弦 + 漂移派生
- 4 个 L 形角标记（每角 `<div>` 带双面边框）位于框上
- 可选标签位于左上角上方，显示类名 + 置信度百分比

全部由 GSAP 时间线驱动，使 HF 确定性定位。

## 关键原则

- **暗背景上的黄色是检测惯例** — 参见 {detectionYellow} 条目。其他颜色失去类型信号。
- **框始终包含目标** — 每帧从目标位置重新计算框位置；从不落后。如果框延迟，读作"追踪器损坏"，而非"智能 AI。"
- **微妙大小变化（SIZE_BASE 的 ~5-10%）** — 太多则追踪器看起来困惑；刚好看作"实时重新计算。"
- **角标记，而非完整边框** — L 形支架是类型标志。完整边框看起来像通用 UI 框。
- **置信度标签在狭窄范围内闪烁（CONFIDENCE_MEAN ± CONFIDENCE_VAR 在 [95, 99] 内）** — 之外读作"不确定"；≥100 读作"假精确。"
- **跟踪不使用 CSS 动画 — 使用时间线 onUpdate** — HF 逐帧定位不与 CSS 动画同步。
