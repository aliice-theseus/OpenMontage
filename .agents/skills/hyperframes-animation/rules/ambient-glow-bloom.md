# 环境辉光绽放

一个柔和径向辉光，在主角元素（卡片、logo、度量）后**绽放**并保持，赋予其存在感。与 `press-release-spring` 的点击触发爆发或 `asr-keyword-glow` 的单词定时包络不同，此辉光是**无触发**的 — 它只在主角稳定时绽放并保持点亮。两种形式：一个**主角辉光**在稳定元素后膨胀然后呼吸，和一个**移动辉光扫过**将柔和高亮一次穿过表面。两者都是有限、确定性和 seek 安全的。

## 工作原理

一个径向渐变层位于主角**之后**（`z-index` 在其下），从 `opacity: 0` 开始。在绽放窗口内它从不透明度 `0 → 峰值` 渐变，伴随温和的 `scale` 膨胀（光晕"膨胀"到位），时间上与主角的稳定对齐，使两者读作一个节拍。

两种形式在绽放后分叉：

1. **主角辉光** — 一旦点亮，辉光在保持期间执行**有界空闲呼吸**。通过读取 `tl.time()` 的 `onUpdate` 驱动它（非 `repeat: -1` yoyo）：一个已过时间的 `Math.sin` 微调 `opacity` 和 `scale` 围绕其峰值。在 `sin(0) = 0` 时呼吸精确地从辉光的休息状态开始 — 无跳跃。
2. **移动扫过** — 表面一条边缘的一个窄高亮渐变**一次**平移到另一边缘（`x` 从表面外到表面外），一个单次有限通过。无循环，无返回。扫过层裁剪到表面，使高亮仅在其重叠处可读。

峰值不透明度保持克制（≤ ~0.45），使辉光赋予存在感而不冲刷画面；辉光颜色比其背衬的元素更深/更饱和。

## 关键原则

- **有意无触发** — 此辉光不等待点击（`press-release-spring`）或单词时间戳（`asr-keyword-glow`）。它在主角稳定时作为环境存在绽放。如果你需要触发的爆发，使用那些规则之一。
- **辉光在后，主角在前** — 辉光 `z-index: 1`，主角 `z-index: 2`。前面的辉光在峰值不透明度时会遮挡主角。
- **辉光颜色比元素更深、更饱和** — 亮主角 → 暗、饱和光晕。相同色调、相同亮度的辉光会消失在表面中。
- **辉光和主角作为一个节拍着陆** — 将 `BLOOM_START + BLOOM_DUR` 时间对齐到主角的稳定。先到或后到的辉光读作两个独立事件；一起到达读作卡片"通电。"
- **克制峰值 — 默认使用低端。** 大多数场景的 `GLOW_PEAK_OPACITY` 0.15-0.30；0.45 是硬上限。你有意识地注意到的辉光太强了 — 它应注册为主角有重量，而非可见光源。
- **呼吸是**有界的**，从不是循环** — 空闲脉冲是读取 `tl.time()`（通过 `phase` 代理）的有限 `onUpdate` 补间，而非 `repeat: -1` / `yoyo`。`sin(0) = 0` 意味着它从辉光的休息状态开始，无跳跃。（与 `sine-wave-loop` 相同原因：无限/CSS 循环会与 HF 定位时钟不同步。）
- **扫过是**一次通过** — 移动高亮从一边缘外进入并从另一边缘外退出一次。无返回行程，无循环。重复扫过读作加载闪烁，而非一次性揭示重音。
- **并发光晕复合** — 一行中 N 个呼吸辉光累加。每辉光的 `OPACITY_AMP` 和 `SCALE_AMP` ≤ 默认值 `/ √N`，并错开呼吸周期（2.6s / 2.9s / 3.3s），使它们不同步脉冲。（与 `sine-wave-loop` 的并发元素规则相同的 `/√N` 规则。）
- **不要将主角上的 `boxShadow` 辉光与此光晕层组合** — 它们在布局管线中竞争，结果读作浑浊。将辉光放在专用的 `.bloom-glow` 层上，而非主角上的阴影。
