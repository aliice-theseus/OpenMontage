# 视觉技巧参考

来自制作中 HyperFrames 视频的 13 个经过验证的技巧。在故事板和构图中使用这些技巧，创建视觉丰富、专业的输出。每个技巧包括一个可以适配的最小代码模式。

这些**不是**高级技巧 — 它们是标准动效设计模式，每个组合应至少使用 2-3 个。

## 内容

- SVG 路径绘制
- Canvas 2D 程序化艺术
- CSS 3D 变换
- 逐词动感排版
- Lottie 动画
- 视频合成
- 逐字符打字
- 可变字体轴动画
- GSAP MotionPathPlugin
- 速度匹配过渡
- 音频响应动画
- Clip-path 揭示遮罩
- WebGL 片段着色器艺术
- 何时使用什么

## 11. 音频响应动画

从播放的音频驱动任何 GSAP 可补间属性。低音在鼓点上脉冲 logo。高音在钹上辉光 CTA。振幅在安静短语期间呼吸背景。

**何时使用：** 任何有音乐或戏剧性旁白的视频 — 品牌展示、产品发布、炒作编辑。对于平静/教程节奏跳过。

## 何时使用什么

| 视频能量                       | 要组合的技巧                                           |
| ------------------------------ | ------------------------------------------------------- |
| 高冲击（发布、宣传）           | 逐词排版 + 速度过渡 + 计数器动画                       |
| 电影感（巡览、故事）           | SVG 路径绘制 + 视频合成 + 3D 变换                       |
| 技术（开发工具、API）          | 字符打字 + Canvas 2D 程序化 + MotionPath                |
| 高级（奢侈品、企业）           | 可变字体动画 + Lottie + 慢速度过渡                      |
| 数据驱动（统计、度量）         | Canvas 2D 程序化 + 计数器动画 + SVG 路径绘制            |
